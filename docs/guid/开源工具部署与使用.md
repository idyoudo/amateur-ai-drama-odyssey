# 开源工具部署与使用（AADO 外链入口）

> 这 3 个开源项目**独立部署**在 AADO 所在服务器，不进入 AADO 的数据库与流水线；AADO 只提供入口链接。
> 选型依据见 [开源项目部署选举记录](../plans/开源项目部署选举记录.md)。

| 工具 | 用途 | 访问地址 | 端口映射 | 状态 |
|---|---|---|---|---|
| ToonFlow | AI 短剧/漫剧全流程：剧本、分镜、角色资产、图/视频生成 | `http://101.200.220.4:18588` | 18588 → 3000 | 已部署 |
| MoneyPrinterTurbo | 一键生成短视频：脚本、素材、字幕、BGM | `http://101.200.220.4:18501` | 18501 → 8501 | 已部署 |

| NarratoAI | 影视解说文案 + 自动剪辑 + 配音字幕 | — | 18503（预留） | 未部署（构建超时） |

所有地址都经过 **Caddy Basic Auth**：

- 用户名：`aado`
- 密码：部署时随机生成，保存在服务器 `/data/runtime/amateur-ai-drama-odyssey/.env.tools`（`chmod 600`）
- 查看密码（在服务器上执行）：

```bash
ssh root@101.200.220.4 'grep ^TOOLS_PASSWORD= /data/runtime/amateur-ai-drama-odyssey/.env.tools'
```

> 当前是 HTTP Basic Auth，密码在网络上是明文传输；请只在可信网络使用。后续可加域名与 HTTPS。
>
> 已从公网验证：`18588 / 18501 / 18502` 带凭据返回 200，不带凭据返回 401。

## 二、首次使用

### ToonFlow（短剧/漫剧主入口）

1. 打开 `http://101.200.220.4:18588`，输入 Basic Auth 账号。
2. 选择服务器工作区内的 `myProject`（数据卷 `/app/data/workspaces/`）。
3. 在设置中接入模型：填写 OpenAI 兼容的 Base URL、API Key 与模型名（文本、图像、视频分别配置）。
4. 新建项目 → 写剧本/分镜 → 绑定角色与场景资产 → 生成关键帧 → 图生视频。
5. 生成任务在浏览器内排队；2 vCPU 下建议一次只跑一个任务。

### MoneyPrinterTurbo（一键短视频/宣发）

1. 打开 `http://101.200.220.4:18501`。
2. 进入「基础设置」填写：
   - LLM：OpenAI 兼容地址、Key、模型名（用于写文案与关键词）；
   - 素材：Pexels / Pixabay Key（免费申请）；
   - 配音：默认 Edge TTS 免费，也可接其他 TTS。
3. 输入主题 → 生成脚本 → 选择素材与配音 → 生成视频。
4. API 文档在 `http://101.200.220.4:18502/docs`，适合后续做批处理。

### NarratoAI（解说/二创，未部署）

> 首次构建在 `uv sync` 阶段超过 28 分钟仍未完成，已中止并标记为外链。服务器上已准备好源码与 Dockerfile，可重跑 `./scripts/deploy-tools.sh` 重试；构建成功后再将其状态改回「已部署」。

1. 打开 `http://101.200.220.4:18503`（仅构建成功后可用）。
2. 在配置页填写 LLM 与 TTS 凭据。
3. 上传视频 → 生成解说文案 → 自动剪辑 → 导出。
4. 生成文件保存在服务器 `narrato/storage`。

## 三、构建说明（本机网络环境适配）

- **MoneyPrinterTurbo**：官方 GHCR 在当前网络不可达，脚本自动回退到 NJU 镜像
  `ghcr.nju.edu.cn/harry0703/moneyprinterturbo:latest`，并打回 `MPT_IMAGE` 标签。
- **ToonFlow**：Docker Hub 的 `oven/bun` 不可达，改用内联 Dockerfile：
  基于本机已有的 `python:3.12-slim-bookworm`，安装 Bun 1.3.14 + ffmpeg 后构建。
  HTTP 公网不是安全上下文，部署脚本会向前端入口注入 `crypto.randomUUID` polyfill；
  更新后浏览器需要硬刷新（Cmd/Ctrl+Shift+R）。
- **NarratoAI**：构建前把 Debian 官方源改写为阿里云镜像；`python:3.12-slim-bookworm`
  使用本机已有镜像标签。首次构建在 `uv sync` 阶段超时（>28 分钟），已中止；可重跑部署脚本重试。
- 构建顺序为串行，避免 2 vCPU 下并发 OOM；构建完成后可执行 `docker builder prune -f` 释放缓存。

## 四、资源纪律（重要）

服务器为 **2 vCPU / 7.2GB RAM / 无 GPU / 40GB 可用磁盘**，同时运行 AADO 与 retail 两套系统：

- **一次只跑一个视频生成/转码任务**；并行会争抢 CPU 与内存。
- 三个工具均设置了内存上限（ToonFlow 1GB、MPT 2GB×2、NarratoAI 2GB、网关 128MB）。
- 视频产物会持续占用磁盘；定期清理 `mpt/storage` 与 `narrato/storage`。
- 不要执行 `docker compose down -v`：会删除 ToonFlow 数据卷。

## 五、运维命令

在服务器 `/data/runtime/amateur-ai-drama-odyssey` 下：

```bash
COMPOSE="docker compose --env-file .env.tools -f docker-compose.tools.yml"
$COMPOSE ps
$COMPOSE logs -f --tail=100 toonflow
$COMPOSE restart mpt-webui
$COMPOSE stop            # 停止全部，保留容器与数据
$COMPOSE up -d           # 重新启动
```

更新某个工具：

```bash
git -C /data/next-ai-ws/open-source/toonflow pull --ff-only
cd /data/runtime/amateur-ai-drama-odyssey
docker compose --env-file .env.tools -f docker-compose.tools.yml build toonflow
docker compose --env-file .env.tools -f docker-compose.tools.yml up -d toonflow
```

或直接在本机重跑 `./scripts/deploy-tools.sh`。

清理构建缓存（不要清理数据卷）：

```bash
docker builder prune -f
```

## 六、故障排查

| 现象 | 处理 |
|---|---|
| 浏览器反复弹登录框 | 密码不对；按第一节命令取密码 |
| 502 Bad Gateway | 应用还在启动或构建失败；`$COMPOSE logs <service>` |
| Streamlit 页面空白/断连 | 检查网关日志；确认 `--server.enableCORS=True` 与 WebSocket 可通过 |
| ToonFlow 启动报 `crypto.randomUUID is not a function` | 前端补丁未生效或浏览器缓存了旧页面；硬刷新，或重跑部署脚本重建镜像 |
| ToonFlow 提示「只允许本机 Toonflow 页面管理设备互联」 | 远程访问不支持 Device Link；改用 Add your own provider 配置模型 |
| ToonFlow 打不开工作区 | 确认数据卷 `toonflow_data` 存在，容器内 `/app/data/workspaces/myProject` 可写 |
| 磁盘不足 | 清理产物与 builder cache；`df -h /` |
| 生成任务卡住 | 2 vCPU 下并发过高；取消其他任务，串行执行 |
