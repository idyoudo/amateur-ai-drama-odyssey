# 模型配置指南（接入真实供应商）

> 目标：把 Mock 自证链路切换到真实供应商，产出真实画面/声音。
> 配置入口：**SPA「模型」页 `/#/models`**（推荐）或**远端 `.env`**。
> 每类模型可配置多个提供商，**同一时间只有一个生效**；填了「模型名 + API Key」即切真实，缺一仍走 Mock。

## 零、六类模型各管什么（先分清职责）

一条流水线里六类模型做六件不同的事，彼此不能替代。最常见的误解是「视频模型会把音乐和音效一起生成」：它只带这一条镜头的**现场声**；配乐、音效与环境声属于成片的声音层，要按剪辑后的时间线单独做。语音与口型也常被混为一谈：语音负责「说」，口型负责让画面里的嘴「看起来在说」。

| 类型 | 代码 kind | 它负责 | 它不负责 | 什么时候可以跳过 |
|------|-----------|--------|----------|------------------|
| 文本 | `text` | 剧本、大纲、对白、提示词 | 画面、声音 | 剧本已定稿，只做镜头返工 |
| 图像 | `image` | 定妆照、参考图、关键帧 | 运动、声音 | 用实拍素材，或已有可用锚点 |
| 视频 | `video` | 镜头画面与动态、现场氛围声 | 配乐、设计音效、精确口型 | 该镜头用实拍素材 |
| 语音 | `tts` | 角色配音、旁白 | 嘴型、音乐 | 用真人配音，或镜头自带同期对白 |
| 音乐 | `music` | 配乐 Cue、音效、环境床 | 对白、画面 | 纯对白戏且不需要氛围 |
| 口型 | `lipsync` | 用配音修嘴型 | 画质、表情、身体动作 | 全景/背影/侧脸、无对白镜头 |

三条边界说明：

1. **声音为什么不能直接用视频自带的**：视频一镜一生成，每镜底噪与房间声不同，切镜会「跳」；配乐要跨镜头铺情绪，音效要对齐动作帧（≤1 帧），环境声要无缝循环，交付还要求分轨 stem 与 −23 LUFS 响度。这些都不是单条镜头能提供的（M8 四层总线：对白 D / 音乐 M / 音效 E / 环境 Amb）。
2. **六类可以混搭不同厂商**：每类独立配置、独立生效、独立降级，例如视频用 Wan 3.0、口型用 Sync.so。但上游输出要能被下游接住——口型供应商分「修复型（视频+音轨）」与「生成型（图片+音轨）」，已有镜头只能交给修复型，否则画面被重新生成，跨镜一致性会断。
3. **口型不是全片都开**：单价通常是语音的 10–50 倍，只对近景正脸 + 有对白的镜头开启；失败时回退为「不做口型」，而不是重抽整条镜头。

### 推荐依据与配置顺序

首选不是唯一答案，按六条标准综合：中文理解、OpenAI 兼容、参考图与一致性、成本、授权合规、稳定性与网络。建议每类配两家，一主一备，可随时切换。

1. **先文本 + 图像**：跑通 6 集试播的剧本与定妆。
2. **再视频**：先做 10–20 个关键镜，验证一致性与单镜成本。
3. **然后语音 + 口型**：口型只对近景正脸镜开启（单价通常是 TTS 的 10–50 倍）。
4. **最后音乐**：商用前确认授权档位并保留凭证。

「设置指南」在模型页左上角与全站右上角图标组都有入口，内含同类推荐与依据。

## 二、怎么配

### 方式 A：SPA 模型页（推荐）
1. 打开 `http://<host>:4000/#/models`（旧地址 `/models` 会自动跳转）→ 登录
2. 每个类型下点整行的「添加提供商」，进入整页厂商目录
3. 目录支持搜索与分组（国内厂商 / 海外厂商 / 第三方平台）；点卡片自动填好名称、模型与 URL，填 **API Key** 后保存
4. 目录里没有的厂商，用第一张「自定义配置」：名称、模型、URL、Key 全部手填，同样可以接入
5. 同类可加多个（如「官方」「中转」「备用」）；只有第一个会自动生效
6. 回模型页点「设为生效」切换；切换后新任务立即使用新提供商，旧提供商配置保留
7. 编辑/删除提供商；删除生效项时，同类型下最近的一个会自动接续
8. 回到项目页运行流水线，即走真实供应商

### 方式 B：远端 .env
在 `/data/runtime/amateur-ai-drama-odyssey/.env` 追加：
```
TEXT_MODEL=qwen3-max
TEXT_API_KEY=sk-xxx
TEXT_API_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
VIDEO_MODEL=kling-v2
VIDEO_API_KEY=xxx
VIDEO_API_URL=https://api.klingai.com/v1
# …image / tts / music / lipsync 同理
```
改后重启 api：`docker compose --env-file .env -f docker-compose.prod.yml up -d --force-recreate api`

> 环境变量只作为兜底：某类型没有任何生效提供商时，才使用 `.env` 的值。

## 三、三条协议（适配器已实现）

| 协议 | 覆盖 | 适配器 |
|------|------|--------|
| OpenAI 兼容（同步） | text / image / tts | `OpenAICompatText/Image/TTS` |
| 异步视频三段式 | video | `AsyncVideoProvider`（创建→轮询→下载） |
| 通用异步任务 | music / lipsync | `AsyncTaskProvider` |

任何**兼容 OpenAI 协议**的供应商（含国内多数中转）都可直接用，只需填其 base URL。

## 四、商业授权红线（务必先锁）

- **Suno**：仅 Pro/Premier 订阅档可商用，且**不保证版权**；免费层不可用。
- **Mureka**：免费层不可商用，付费 API 产物才有完整商业授权。
- **ACE-Step**：Apache-2.0，可自托管，版权最干净（推荐首选）。
- **InsightFace 系**（ArcFace/INSwapper）：**仅限非商业研究**，商用须另行授权或替换。
- **ComfyUI / HunyuanVideo**：GPL/非 OSI，**不得内置分发**，只能外部服务或云 API。

> 未达授权档的 AI 曲目/素材禁止进成片（M8.6-F01 / M18.1）。

## 五、成本锚点（用于预算，M14）

- 视频：按秒计费（1080P 约 ¥1/秒级），是主要成本项。
- 口型：单价是 TTS 的 10–50 倍 → 策略「只做近景正脸镜」。
- 图像：单图分币级，best-of-n 抽卡近免费。
- 目标（NFR-04）：单位可交付母版成本 P1 ≤ ¥400/分钟、P2 ≤ ¥200/分钟。

## 六、验证

配好后：
```bash
ssh root@<host> 'docker exec amateur-ai-drama-odyssey-api-1 curl -s http://127.0.0.1:4000/api/models/config'
```
返回的 `available` 应含你配置的 kind；`providers.<kind>` 会列出全部提供商与 `active` 标记，且同类只有一个 `active=true`。再运行流水线，供应商卡片会显示「真实」而非「Mock」。

安全说明：API 永不回传明文 Key（只返回 `api_key_set` 与末四位 `api_key_hint`）；编辑时留空 Key 表示「保留原值」，清除需显式勾选；删除生效提供商会自动接续同类最近一个。配置写入数据库 `model_providers` 表（旧版 `model_configs` 的每条记录会在首次启动时自动迁移为「默认配置」提供商），生产需使用持久化 `DATABASE_URL`；默认内存库重启后丢失。
