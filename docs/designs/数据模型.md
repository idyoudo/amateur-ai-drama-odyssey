# AADO 数据模型（docs/plans/数据模型.md）

> 目标态表结构、字段、约束、迁移。技术栈：PostgreSQL 16 + SQLAlchemy 2.0 + Alembic。
> 借鉴来源：RTO `apps/api/src/dramaService.ts:10-39`（drama_* 表）+ audit `packages/db/src/schema.ts`（outbox/幂等/乐观锁）。
> 迁移纪律：**只增不删、Alembic 版本化**（补齐 RTO「内联 `ALTER ADD COLUMN`」短板）。所有表带 `created_at`/`updated_at`。

## 一、领域核心表

### projects（项目/立项，M1）
```text
id, workspace_id, title, logline, status, package_preset(M1.0-F02),
target_delivery(M12 交付规格清单 JSONB), budget_profile(M14 四级预算 JSONB),
pilot_mode(bool, M1.3-F05), adapt_checkpoint JSONB(续跑), created_at, updated_at
```

### episodes（集，M1/M9）
```text
id, project_id, episode_no, script_ref, status, duration_target_sec,
asl_target, timeline_ref, created_at, updated_at
```

### shots（镜头，M4/M5/M6 —— 契约唯一事实源）
```text
id, episode_id, shot_no, scene_id,
contract JSONB   ← M4/M5 契约（景别/角度/主运镜/焦距档/景深意图/三点光/CCT/体积光介质/物理骨架，
                    由 film/contract 封闭枚举校验后写入）
subject_geometry JSONB ← 构图几何（subject_x/y/scale + 来源声明）
prompt_sha256, snapshot JSONB(M5.2-F05 摄影参数快照),
status, image_key, video_key, retake_count, created_at, updated_at
```

### look_bible / characters（M3 选角/形象圣经）
```text
characters: id, project_id, name, voice_key, anchor_assets JSONB(锚点图集 ≥3 张),
            identity_embedding, consent JSONB(数字替身授权), status(定妆门禁), created_at
look_bible: id, project_id, version, spec JSONB(角色/场景/道具/色彩/光线统一规范), locked_by, locked_at
```

### gates（五门禁，M10/M16 —— 字段契约层已实现）
```text
id, project_id, node(script/casting/board/picture/master), decision,
approver, role, reason_code, timestamp, binary_checklist JSONB,
ai_recommendation, ai_overridden, override_reason, written_reason,
evidence JSONB, created_at
```

### reviews（质检/返工，M10）
```text
id, shot_id, layer(画面/音频/一致性/口型/连续性), metric JSONB, verdict, reason_code, reviewed_by, created_at
```

## 二、任务与可靠性表（M13，核心借鉴）

### jobs（任务队列，RTO `drama_jobs` 移植）
```text
id, project_id, episode_id, shot_id, type(stage enum),
status(queued/running/completed/failed/cancelled/unknown),
progress, error_code, error_class, attempts, attempt_limit,
available_at, locked_until, lease_epoch(单调递增，fencing),
idempotency_key, provider_task_id, checkpoint JSONB, created_at, updated_at
-- 约束：UNIQUE(project_id, idempotency_key)；索引(status, available_at)
```

### intents（intent log，M13.4-F05，audit 移植）
```text
id, job_id, provider, fingerprint, client_op_id, request_id,
payload_frozen JSONB, status(intended/submitted/unknown/resolved), created_at, updated_at
-- 语义：调用供应商前先落盘；超时置 unknown 进对账；已提交绝不重投
```

### outbox（幂等出站，audit 移植）
```text
id, job_id, topic, payload JSONB, idempotency_key UNIQUE, version(乐观锁),
status(pending/sent/failed), attempt_count, next_attempt_at, claimed_at, sent_at, created_at
```

## 三、资产与血缘（M15）

### assets（媒体资产，RTO `drama_assets` 移植）
```text
id, project_id, kind(image/video/audio/stem/subtitle/master/derived),
object_key, bytes, checksum_sha256, provider_task_id,
parent_asset_id(血缘), generation_param JSONB, created_at
```
**血缘规则**：派生版本（2.39/16:9/9:16/5.1/HDR10）必须 `parent_asset_id` 指向 16:9 open gate 母版，禁止单画幅重复生成（EL-01）。

## 四、成本与供应商（M14/M17）

### usage_records（调用级计量，M14.1-F02）
```text
id, project_id, shot_id, provider, model, fingerprint, amount_cny, tokens, created_at
-- 指纹去重 → 重复付费调用 = 0（NFR-01）
```

### suppliers（能力矩阵，M17.1-F04）
```text
id, name, capability JSONB(视频/图/口型/TTS/音乐 各维度 + 电影参数支持度),
auth JSONB(凭证引用，不落明文), rate_limit JSONB, circuit_state, updated_at
```

### budgets（四级预算 + 额度预占，M14.2）
```text
id, project_id, level(project/episode/pod/shot), cap_cny, reserved_cny, consumed_cny,
trigger JSONB(熔断阈值), created_at
```

## 五、迁移与一致性纪律

1. Alembic 版本化迁移；**禁止**内联 `ALTER TABLE` 直改生产。
2. 枚举用 PG enum（audit 的教训：状态机必须类型化，不要用 JSONB + 字符串码混搭）。
3. 所有 `contract JSONB` / `snapshot JSONB` 写入前必须过 `film/` 的封闭枚举校验，非法值拒绝（对齐 P1-A 切片）。
4. `已实现` 功能点的代码证据格式统一 `path:行号`（GOVERNANCE 强规则二）。
