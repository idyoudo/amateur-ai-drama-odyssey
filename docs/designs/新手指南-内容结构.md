# 新手指南·内容结构

> 入口：侧边栏「制作 → 新手指南」，路由 `#/guide`。
> 目标：让第一次接触短剧与 AADO 的用户，在一页内完成「看懂流程 → 认识术语 → 知道为什么火 → 按专业方案开工」。

## 页面结构（单页有序分区）

1. **导读卡**：一句话解释短剧是什么，并提供页内跳转（大白话流程 / 术语小抄 / 为什么会火 / 7 天上手 / 专业版方案）。
2. **大白话流程（12 步）**：定方向 → 写故事 → 定角色 → 画分镜 → 生成画面 → 保一致 → 配音口型 → 做声音 → 剪辑字幕 → 调色母版 → 交付分发 → 数据复盘。每步包含「大白话解释」与「在 AADO 里怎么做」。
3. **术语小抄**：短剧、logline、景别、运镜、分镜、钩子/断章、爽点、母版、交付规格、IAP/IAA、完播率、Mock。
4. **为什么会火**：前 3 秒、冲突升级、结尾断章、情绪回报、标题封面、视觉奇观；注明是结构规律，不保证结果。
5. **新手 7 天上手计划**：从示例项目到完整交付，每天 1–2 小时。
6. **专业版使用方案**：
   - 9 个阶段表（关键产出 / 对应 AADO 模块 / 通过门禁）；
   - 角色分工（管理员、制片、导演、编剧、剪辑、QC、法务）；
   - 交付硬指标（2.39:1、24fps、Rec.709 SDR、−23 LUFS、≤−1 dBTP、24-bit/48kHz）；
   - 90 天节奏；
   - 三张清单（开工前 10 项、每集 6 项、交付前 8 项）；
   - 直达按钮（新建项目、示例项目、爆款分析、资产库、模型配置）。

## 维护约定

- 内容为前端静态文本，位于 `apps/api/static/app.js` 的 `viewGuide()`；样式在 `app.css` 的「G1：新手指南」段。
- 调整交付规格、页大小或模块名称时，同步更新本页对应文案，避免教程与产品不一致。
- 不放入播放量承诺、收益承诺或未核验数据；「为什么会火」必须保留「不保证结果」的说明。
- 保持整页分区与留白，不做挤牙膏式向导或弹窗。
