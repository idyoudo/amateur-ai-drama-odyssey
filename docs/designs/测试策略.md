# AADO 测试策略（docs/plans/测试策略.md）

> 对齐 `PRD/90` 第八章「验收证据来源」。核心纪律沿用本仓库已验证的：**生成与复测分离、fail-closed、
> 变异测试证明规则有牙、实测数据驱动报告**（见 [docs/agent-prd-method.md](../agent-prd-method.md)）。

## 一、测试分层

| 层 | 对象 | 工具 | 证据落点 |
|----|------|------|----------|
| L1 单元 | `film/` 纯函数（契约枚举/提示词编译/几何/漂移/快照） | pytest | `docs/spec/` 单测记录 |
| L2 集成 | 队列/幂等/checkpoint/intent log/fencing（`film/jobs`） | pytest + 测试 PG | `docs/spec/` 集成记录 |
| L3 机检门禁 | 可机检产物（响度/安全框/字幕/黑场/ΔE/AI 标识） | 独立复测脚本（只读磁盘产物） | `out/*/qc_report.json` |
| L4 人工观感 | 画风/节奏/表演/故事 | 抽检评分表 | 门禁署名记录 |

## 二、关键纪律（每条都是踩坑换来的）

1. **生成与复测分离**：生成器写产物；复测器只读磁盘产物、**不 import 生成器**、fail-closed。复测晚于被检对象产生，先校验产物存在且非空。
2. **变异测试配平**：每条校验规则配一个违例样本；断言「规则注册表 == 变异样本集合」，漏一条即 FAIL（杜绝恒真断言）。
3. **负样本必须失败**：注入已知违规构图/参数，规则必须判 FAIL——证明规则有牙。
4. **锚点互核**：用同一判据量独立来源（参考实现），证伪「自证假通过」。
5. **实测驱动报告**：`report.py` 由产物 JSON 生成 md，**禁止手抄数字**（本仓库 C-07 是手抄漂移事故）。
6. **阈值诚实**：官方未给统一值的阈值标「项目自定」，写入 `declared_thresholds.json` 并带 source；`待补原文` 不得作验收阈值。

## 三、验收证据格式（对齐 `PRD/90` 第八章）

| 验收类型 | 证据形式 | 机读格式 | 提供方 |
|----------|----------|----------|--------|
| 功能可用 | 操作路径 + 截图/录屏 | — | 开发 |
| 自动化 | 单测/集成记录 | pytest XML/JUnit | 开发 |
| 技术合规 | 自动检测报告 | `qc_report.json`（字段固定） | 流水线 |
| 感知质量 | 质检报告 | `review.json`（metric+verdict+reason_code） | 质检流程 |
| 声音 | 响度/真峰值/可懂度/下混 | `audio_qc.json` | 混音 |
| 色彩母版 | 色偏统计+标签核查+规格校验 | `master_qc.json` | 调色/母版 |
| 合规 | AI 标识存在性+权利链+分级 | `compliance.json` | 法务 |
| 人工观感 | 抽检评分表 | `gate_receipt.json`（署名+理由码） | 内容负责人 |

## 四、CI 接线

- 提交：`tools/prd_guard.py --staged`（强规则一）+ 单元测试。
- PR：`tools/prd_guard.py --all` + `demo/verify.py`（24/24 回归）+ `tools/verify_p1_a.py --determinism` + L2 集成。
- 门禁全绿才算可合并；任一 FAIL 阻断。
