# 开源调研报告：短剧 / 漫剧 / 视频类顶级项目

> 目的：调研 GitHub 顶级开源短剧/漫剧/AI 视频项目，提炼可**吸纳到 AADO** 的功能，供 5 人选举裁决。
> 方法：实读各项目 README/文档 + 一篇横向管线调研；star 与日期为抓取当日（2026-10）。**只参考，不照搬**；AADO 是**好莱坞级**（2.39:1/24fps/−23 LUFS/五门禁/交付规格），与微短剧/漫剧定位不同。

## 二、共性流水线（各家基本一致）

想法 → 剧本/剧集圣经 → **锁定角色与场景参考图** → 分镜/镜头表 → **从参考图做 image-to-video** → 配音剪辑成片。
跨镜一致性靠「**先立参考、后生成**」。AADO 已有：M2 剧本、M3 角色锚点、M4 分镜、M5 摄影、M17 r2v 视频适配——**骨架一致**。

## 三、候选吸纳功能（差异点，AADO 尚缺）

| # | 功能 | 出处 | 价值 |
|---|------|------|------|
| C1 | **四层连贯性记忆**（全局快照/上章结尾/更早摘要/关键词账本，各设硬上限） | huohuo | 长篇跨集不跑偏；AADO 目前各集独立 |
| C2 | **因果链变更记录**（每场 Change Record：触发→过程→结果，跨章审计） | huohuo | 剧情逻辑可追溯；补 M2 结构校验之外 |
| C3 | **双管线降级**（AI 视频 / 帧幻灯片 Ken Burns+时长对齐TTS） | huohuo | **无视频额度也能出片**；对 AADO 无付费凭据环境价值极大 |
| C4 | **首尾帧锚定链**（上一镜尾帧→下一镜首帧，解决分段接缝） | LocalMiniDrama/huohuo | M6.2-F04 已提但未实现；接缝质量 |
| C5 | **填充式生成**（「生成全部」跳过已生成，只补缺失；自动重试 429） | LocalMiniDrama | 省时省钱；对齐 M13 幂等但需 UI 化 |
| C6 | **生成前成本确认闸**（花额度前逐镜摊开待人工点头） | Nomi 最佳实践/DramaClaw | 防跑飞；对齐 M14 硬阻断但需「预演确认」 |
| C7 | **发布锁定 + 签名收据**（有序发布 YouTube→抖音 + signed receipt） | Qingshan | 交付可举证；对齐 M12 三重放行 |
| C8 | **资产编号参考槽位**（提示词 `@图片N` 对齐 场景→角色→道具） | LocalMiniDrama/Seedance2 | 参考图挂载标准化；补 M6.2-F01 |
| C9 | **画布模式**（节点式工作流画布，脚本节点/右键/悬浮工具条） | LocalMiniDrama/waoowaoo | 可视编排；大幅改动，成本高 |
| C10 | **AI 检测/去 AI 改写**（合规发布） | huohuo | AADO M18 已含 AI 标识；去 AI 改写属内容处理，边界外 |

## 四、AADO 已具备（无需吸纳）

角色圣经/锚点（M3）· r2v 视频（M17）· 结构化分镜（M4）· 五门禁审查点（M10/M16）· 自动重试与失败分类（M13.7）· 交付三重放行（M12.4）· 契约层质量门（全模块）· 幂等/断点续跑（M13）。

## 五、结论

**建议吸纳：C1–C8**（C9 画布成本过高暂缓、C10 边界外）。其中 **C3 双管线降级** 与 **C5 填充式生成** 对 AADO「无付费凭据」环境价值最大；**C1/C2 长篇记忆与因果链**是 AADO 相对微短剧工具的差异化增强。
最终以 5 人选举裁决（见 `docs/plans/开源吸纳-选举记录.md`）。
