# 商业化改进候选（UI / 业务 / UX / 性能）—— 待 5 人选举

> 目标：从「可用 Demo」提升到**商业产品级**。候选按四维度列出，由 5 人选举定优先级。

| 编号 | 维度 | 候选 | 做法 | 商业价值 |
|------|------|------|------|----------|
| C1 | UI | **组件状态完整 + 设计系统收敛** | 按钮/输入/表格/徽章/弹窗补齐 hover/focus/disabled/loading/error 态；统一 token；表单校验提示 | 专业感与可维护性 |
| C2 | 业务 | **项目生命周期看板** | 状态机：立项→制作中→待审→已交付→归档；列表看板视图 + 阶段进度 | 多项目管理 |
| C3 | 业务 | **多用户 / 岗位 / 邀请 / 审计** | 用户表 + 岗位分配 + 成员管理 + 操作审计流水 | 团队协作（SaaS 基础） |
| C4 | 业务 | **通知与待办中心** | 门禁待签、失败待处理、预算超限聚合；铃铛入口 + 未读计数 | 不漏单、可运营 |
| C5 | UX | **全局搜索 + 命令面板（⌘K）** | 跨项目/资产/任务搜索；命令面板快捷跳转与操作 | 效率与专业感 |
| C6 | UX | **引导与示例项目** | 首次进入引导 + 一键创建示例项目 + 空状态行动指引 | 上手转化 |
| C7 | 性能 | **分页 + 索引 + 虚拟列表** | API 分页/过滤；DB 索引；长列表（数百镜头）虚拟滚动 | 大数据量可用 |
| C8 | 性能 | **缓存 + 惰性加载 + 静态资源** | 前端请求缓存与去重；图片/字体优化；首屏体积控制 | 响应速度 |

## 评估维度

商业价值 / 用户是否立刻感知 / 实现成本 / 风险 / 是否阻塞其他能力。
