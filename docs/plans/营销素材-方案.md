# 营销素材方案（文案 / 海报 / 预告 / 视频）

> 目标：为每部短剧自动生成可直接投放的营销素材，覆盖文案、海报、预告片分镜、动态预览与可下载视频。

## 一、生成内容

- **多平台文案**：标题变体、前 3 秒钩子、红果漫剧/抖音短剧/快手星芒/YouTube Shorts/YouTube 长视频文案与话题标签。
- **海报**：9:16 与 16:9 两张 SVG 海报（片名、钩子、规格、分级、AI 标识）。
- **预告片分镜**：冷开场 → 4–6 个镜头/情节点 → 悬念收尾，含时长、字幕、转场、来源镜头。
- **HTML 动态预览**：独立 HTML，自动轮播标题/钩子/分镜，可离线打开。
- **视频素材**：浏览器 Canvas + MediaRecorder 录制 9:16 **WebM**，时长约 15–25 秒，可直接下载；平台如要求 MP4 需转码。
- **素材包 ZIP**：海报 SVG、文案 TXT/JSON、预告 JSON、promo.html、说明。

## 二、接口

- `GET /api/dramas/{id}/marketing-kit`：文案、海报 SVG、预告分镜、免责声明。
- `GET /api/dramas/{id}/marketing-kit/promo.html`：独立动态预览 HTML。
- `GET /api/dramas/{id}/marketing-kit.zip`：素材包下载。

生成完全基于项目数据（标题、logline、题材、镜头/台词），不依赖付费模型；没有镜头时用 logline 拆句生成情节点。

## 三、页面

- 「营销」页：项目选择、文案列表（一键复制）、平台文案、预告分镜表、9:16/16:9 海报预览、WebM 录制。
- 项目详情顶栏提供「营销素材」入口，自动带入当前项目。
- 整页布局：左侧文案与分镜，右侧海报与视频。

## 四、非目标

- 不做真实 MP4 编码（无 ffmpeg/GPU）；WebM 由浏览器录制，MP4 需转码。
- 不接广告投放平台（投流、素材 A/B、Push 仍待后续）。
- 不做 AI 文案生成（当前为规则模板，避免凭空编造剧情）。
