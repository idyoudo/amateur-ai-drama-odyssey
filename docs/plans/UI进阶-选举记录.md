## 强制缓解（已落地）

- **E1**：仅概览页；高度 `clamp(280px,38vh,400px)`；无 scroll-linked 收缩；不劫持滚动；概览顶栏隐藏重复 h1；氛围只用单色阶 + 1px 细线；stats 在首屏下缘可见。
- **E2**：按项目 id 确定性取色（5 组低饱和 tonal ramp，禁止彩虹/高饱和）；封面 16:9 + 衬线片名；无图时纯排印封面；对比度 ≥4.5:1。
- **E3**：大标题放**内容区**（`.page-title`），顶栏只留面包屑；`clamp(28–38px)`；`text-wrap:balance` + `word-break:keep-all`；窄屏降档。
- **E4**：全部硬编码色 token 化（滚动条/选区/按钮 hover/tag/遮罩/封面）；深色只覆盖 token，不加组件补丁；`color-scheme`。
- **E5**：仅 `.view` 级入场（opacity + 8px，≤220ms，`var(--ease)`）；**不做**数字滚动、**不做** hover-only 信息、**不做** stagger/视差；全局 `prefers-reduced-motion: reduce` 关闭动画与过渡。
