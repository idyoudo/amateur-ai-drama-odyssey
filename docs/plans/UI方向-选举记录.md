# UI 方向选举记录（5 人一致）

> 候选见 [UI重设计-调研与方向.md](UI重设计-调研与方向.md)。用户诉求：**现代化、高级感、偏浅色**。

## 结果

| 方向 | 票 | 结论 |
|------|-----|------|
| **D1 · Editorial Neutral（编辑风中性）** | **5:0** | ✅ **定稿** |
| D4 · Soft Depth（柔和纵深） | 0 票（5 人列为次选） | 未选 |
| D2 · Warm Studio | 0 | 未选 |
| D3 · Monochrome Precision | 0 | 未选 |

**一致理由**：D1 同时命中最硬约束——微灰绿基底 `#F7F8F7`（非纯白，2026 Cloud Dancer 趋势）× 单一靛蓝强调色 × 1px 极浅边框 + 背景色差分层；气质克制精确，契合**密集数据、长时间使用**的电影制作工具；改动成本最低（现有 CSS 全变量驱动）。

**一致风险**：靛蓝偏「通用 SaaS」，可能丢电影品牌识别；`#6366F1` 作白底小字不足 AA。

**一致缓解（已落地）**：
- 交互/文本色用加深靛蓝 **`#4F46E5`**（对白底 ≈5.9:1，达 AA）；`#6366F1` 仅作填充。
- 品牌身份下沉到标识层（logo 深色 + 极淡遮幅母题），不做暖色主色。
- 数字/时间码统一 **JetBrains Mono + tabular-nums** 强化「精密仪器」质感。
- 语义色（ok/bad/warn/info）严格独立，不并入靛蓝。

## 定稿设计（D1）

| token | 值 | 用途 |
|-------|-----|------|
| `--bg` | `#F7F8F7` | 页面底（微灰绿，非纯白） |
| `--panel` / `--panel2` / `--panel3` | `#FFFFFF` / `#F4F5F6` / `#EDEFF1` | 三层表面 |
| `--fg` / `--dim` / `--dim2` | `#18181B` / `#71717A` / `#A1A1AA` | 文字三级 |
| `--acc` / `--acc-fill` | `#4F46E5` / `#6366F1` | 交互（AA）/ 填充 |
| `--line` / `--line2` | `#E4E4E7` / `#D4D4D8` | 边框 |
| `--ok`/`--bad`/`--warn`/`--info` | `#10B981`/`#EF4444`/`#F59E0B`/`#0EA5E9` | 语义色 |
| 字体 | Inter + JetBrains Mono | 正文/数字 |
| 圆角 | 10 / 14 px | 控件 / 卡片 |

深色作为**可选**主题保留（设置页可切，`body.dark`）。
