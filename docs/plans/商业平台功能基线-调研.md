# 商业短剧平台功能基线调研与 AADO 差距

> 问题：主流商业短剧平台是否只有 AADO 当前这些功能？答案是否定的。商业平台除了制作链路，还包含运营、分发、协作、数据与本地化层。

## 一、商业平台的功能栈（2026）

| 层 | 典型能力 | 代表 |
|----|----------|------|
| 内容生产 | 剧本、选角、分镜、生成、剪辑、母版、QC | ReelShort/DramaBox 自制、LumenX/Toonflow 开源管线 |
| 资产与 IP | 角色锚点、场景、镜头、素材库、版权与授权 | 点众内容中台、短剧创作者中心 |
| 协作与审核 | 项目成员、角色权限、审核意见、版本与审批 | 短剧创作者中心、企业私有化平台 |
| 分发与发布 | 多平台渠道、排期、发布状态、平台合规适配 | 红果/抖音/快手/YouTube、短剧创作者中心 |
| 数据分析 | 播放、完播率、点赞、转化、收入、ROI | 各平台创作者后台 |
| 商业化 | IAP 解锁、IAA 广告分账、订阅、分成结算 | ReelShort/DramaBox、红果/点众 |
| 本地化 | 多语言字幕、配音、地区化分级与元数据 | 出海短剧平台 |
| 合规 | AI 标识、版权备案、内容分级、审计 | 红果/抖音漫剧新规 |

开源项目（LumenX、Toonflow）强在「小说 → 剧本 → 分镜 → 图像/视频」的生成管线，弱在商业运营层；AADO 在 19 模块治理、QC、交付与合规模拟上已超过它们，但此前缺少分发、运营数据与审核协作。

## 三、本轮落地

### 分发中心
- 渠道：红果漫剧、抖音短剧、快手星芒、YouTube Shorts、YouTube 长视频。
- 录入项目 + 渠道 + 排期 + 备注；状态机：待排期 → 已排期 → 已发布 → 已下架。
- 运营数据：播放、点赞、完播率、营收、外链；支持编辑与汇总。
- 看板：已发布/已排期数量、总播放、总营收、各渠道对比条。
- 数据来源为本地登记，未接平台 API 时明确标注 **Mock 数据**。

### 审核中心
- 审核对象：项目/剧集/镜头/交付。
- 状态：待审 → 通过 / 驳回；记录审核人、意见、更新时间。
- 用于导演/制片/QC 的协作闭环，替代纯口头审批。

## 四、后续路线（按商业价值排序）

1. 字幕与多语言本地化：字幕轨/SRT/翻译稿已完成；配音本地化与机器翻译仍待接服务。
2. 项目级模型路由（按项目覆盖全局供应商配置）。
3. 团队与角色权限（制片/导演/编剧/剪辑/QC/法务）。
4. 模板与提示词库（可复用分镜/运镜/风格模板）。
5. IAP/IAA 结算对账（需真实平台数据源后接入）。
6. 真实渠道发布 API（需平台授权）。
