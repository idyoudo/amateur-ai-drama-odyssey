# P1 拍板项选举记录（6 项可选举拍板）

> 依据 AGENTS.md 工作方式：5 名独立评估员、背对背、多数决；每位给胜出理由（带实读出处）/最大风险/强制缓解/落选覆盖。
> 本记录固化「P1-开发范式与自主决策协议」第五节的 6 项可选举拍板。多数决结果如下（平票加选未触发）。

## 1. NFR-04 成本目标 —— 全票 (a)
- **结论**：P1 ≤¥400/分钟、P2 ≤¥200/分钟；P2 标注「待实测校正」。
- 票数：(a)×5。
- 理由：M14 待确认问题已载 L1 NFR-04 为该值；M14.1-F01 目标值可配置。
- 风险：P2 未经实测可能失真。
- 缓解：先导集三项成本/质量实测（EL-12）后冻结 P2；硬阻断落到四级预算而非单位成本目标。
- 落选覆盖：(b) 更保守由「可配置目标 + 分级预警」覆盖；(c) 先实测由「P1 绑定、P2 待校正」覆盖。

## 2. 工具链采买 —— 全票 (a)
- **结论**：自建纯 Python 检测 + ffmpeg 仅作生产加速路径（ProRes 母版编码必需）。
- 理由：architecture.md 已定「film/ 为唯一事实源、ffmpeg 可选加速」。
- 风险：纯 Python 无法产出 ProRes 母版。
- 缓解：ffmpeg 定位为 ProRes 母版编码必需加速；QC 正确性用 film/ 纯 Python 在 CI 自证；静默降级=0。
- 落选覆盖：(b) 第三方 QC 由 M11.5-F01 FFmpeg 可覆盖项承接；(c) 检测自研由 film/ 自证核心覆盖。

## 3. M19 VFX 自建 vs 外包 —— 全票 (a)
- **结论**：关键镜自建（角色脸/物理骨架）+ 量镜外包（天空/去杂物/粒子）。
- 理由：M19 第二轮决议 D9 已定。
- 风险：关键镜/量镜分界未落到镜头清单。
- 缓解：M19.1-F01 shot list 开拍前 100% 登记 + M19.1-F03 物理骨架通道判定 + 预算上限。
- 落选覆盖：全自建由「高价值关键镜自建」覆盖；全外包由「量镜批量外包」覆盖。

## 4. ACES IDT 落地形态 —— 全票 (a)
- **结论**：自建 LUT 链分档（不引入 OCIO、不按供应商各建）。
- 理由：M11.1-F01 AI 素材无相机元数据、多已烘焙显示参考；纯 Python 无 OCIO C++ 依赖。
- 风险：自建链色彩科学正确性风险。
- 缓解：M11.1-F02 色卡/灰阶 3–5 hero shot 往返验证；M11.1-F03 版本化可回滚；纯 Rec.709 降级兜底。
- 落选覆盖：OCIO 的配置版本化由自建 LUT 台账覆盖；逐供应商 IDT 由「来源→管线分档映射」覆盖。

## 5. InsightFace 非商用替代 —— 4:1 多数决 (b)
- **结论**：自研轻量人脸比对（(a) 仅 VLM 复核得 1 票；评估员1 理由为 DINO/CLIP/SAM 定量指标兜底）。
- 理由：M6.3-F01/F02 要求每镜 ≥2fps 人脸嵌入余弦定量门禁，VLM 仅覆盖灰区无法承载主干；(c) 采购可商用违背无付费凭据。
- 风险：自研嵌入精度可能低于 ArcFace，阈值待标定。
- 缓解：阈值自有剧集数据重标定后冻结；分位截断兜底；灰区 VLM 三次采样复核；季度标定可回滚。
- 落选覆盖：(a) 的 VLM 复核保留为灰区兜底（M6.3-F08）；(c) 由「许可台账留口、有付费凭据后替换可商用模型」覆盖。

## 6. 五门禁审批责任岗位 —— 全票 (a)
- **结论**：按 M16 岗位矩阵绑定（剧本=编剧/showrunner、定妆=导演、分镜=导演、成片=导演/QC、母版=调色/QC/法务）。
- 理由：M16.2-F01/F02/F03 已定义岗位 + 权限矩阵 + 禁自审自批。
- 风险：小团队无人可轮。
- 缓解：一账号兼多岗但同门禁不自审自批；并行审片队列；回溯抽检 ≥10%。
- 落选覆盖：showrunner 统签由「剧本门禁绑 showrunner 兜底」覆盖；外部审片人由「只读候选池、不作署名审批人」覆盖。
