## 关键论据（摘要）

- **C3 双管线**：唯一能在「无视频额度/无 ffmpeg」环境出片的降级路径，与 AADO 纯 Python 降级哲学同构；**必须标 PROXY，不得冒充母版**。
- **C1/C2 长篇记忆与因果链**：AADO 各集独立生成是真实缺口；纯文本状态、无外部依赖，落 M2。
- **C4 首尾帧**：本就是 AADO PRD P0（M6.2-F04），开源做法直接落地；M17 能力矩阵已含 `first_last_frame`。
- **C6 成本确认闸**：补 M14「事前」控制点（M14 现为事后熔断）。
- **C7 收据**：把 M12 三重放行升级为可举证、不可抵赖；渠道实投超范围，只取锁定+收据。
- **C5 否决理由**：M13 已有幂等键/checkpoint/失败分类/自动重试，C5 净增仅批量 UI。
- **C9/C10 否决理由**：分别与「控制面最小化」和「M18 AI 标识合规」直接冲突。
