# 商业化改进·第二轮候选（D1–D6）

> 在第一轮（C1/C7/C8/C4/C6/C2/C5）落地后，继续补齐商业产品能力。

| 编号 | 维度 | 候选 | 做法 | 价值 |
|------|------|------|------|------|
| D1 | 性能/体验 | **字体自托管 + 子集化** | 自托管 Inter / Instrument Serif / JetBrains Mono（woff2 + 子集 + font-display swap + preload），移除 fonts.googleapis.com 依赖 | 国内首屏不阻塞、离线可用 |
| D2 | 性能 | **分镜长列表虚拟滚动** | 数百镜头只渲染视口附近；保留选择/批量/抽卡交互 | 大数据量不卡顿 |
| D3 | 业务 | **多用户最小闭环** | 用户表 + 密码哈希 + 登录 + 岗位 + 按人待办/署名 | SaaS 基础（评估员上轮标高风险 P2） |
| D4 | 业务 | **项目生命周期流转** | 立项→制作中→待审→已交付→归档 的显式写操作（归档/恢复/提交审核）+ 看板操作 | 多项目可运营 |
| D5 | 性能 | **API 游标分页** | shots/assets/jobs 的 `cursor` 分页 + 前端「加载更多」 | 大数据量稳定 |
| D6 | 体验 | **交付/母版可视化增强** | 版本谱系树 + QC 逐项时间线 + 交付单在线预览 | 交付可举证、可演示 |

## 评估维度

商业价值 / 用户感知 / 实现成本 / 风险 / 对已有能力的依赖。
