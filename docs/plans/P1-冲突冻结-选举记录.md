## 二、胜方核心理由（逐条，带出处）

- **C-02**：M5:34 明示「平台无光圈参数，景深只能靠措辞与构图实现」，「中」无独立可实现语义；下游 bokeh 规则（M5:35）只分支 shallow/deep。
- **C-03**：3000K 是实用卤钨/暖光常见档（96:80 S07「hard key low」），扩档不删不改任何既有五档，集合外值仍被 R-CCT-CLOSED 拒绝。
- **C-04**：六 mm 与六档名可一一双射，135mm 属超长焦不能并入长焦（96:80 S07 即 135mm ECU），键集相等可机检断言。
- **C-06**：M11 已在 P1 且自持 −23 LUFS QC（M11.5-F03）与 TC 嵌入（M11.3-F01/F05），退出标准无需放松也无需挪 M8/M9。
- **C-08**：D1 最大风险即 9:16 塌陷（93:37），多画幅安全框（93:39）是唯一对冲；返修使参考实现真实合规，收窄判据等于拆掉对冲。
