# AADO 自主打磨清单（自驱动迭代的判定依据）

> 目的：让「是否打磨完成」**可机器判定**。自主迭代会话每次开工先读本清单，取**第一条未打勾**的项执行，
> 完成后打勾并追加一行执行记录；**未全部打勾不得停下**。完成后写「全部完成」并停止迭代。
> 规则来源：`AGENTS.md`、`docs/plans/P1-开发范式与自主决策协议.md`。主目标：好莱坞级 AI 短剧，web 可从入口看到成果。
