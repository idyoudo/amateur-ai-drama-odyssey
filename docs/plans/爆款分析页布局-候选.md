# 爆款分析页布局·候选（L1–L4）

> 背景：当前页面把「我们自己项目体检」与「他人爆款案例库」混在一页，且项目选择用下拉框；项目一多就不可用。
> 目标：一眼分清「我们的项目」与「他人案例」，项目选择可搜索、可翻页，保持大气整页布局。

| 编号 | 方案 | 做法 | 优点 | 风险/成本 |
|------|------|------|------|-----------|
| L1 | 同页双区 | 顶部统计；「我们的项目体检」区用搜索 + 分页项目表，选中后在下方展示体检；下方独立「爆款案例库（他人作品）」区，明确标注来源 | 改动小、信息集中 | 页面较长，两个大区仍需滚动区分 |
| L2 | 左右分栏 | 左侧「我们的项目」搜索/分页列表，右侧固定体检详情；下方独立「爆款案例库」区 | 项目多时切换快，体检始终可见 | 窄屏体验一般；页面高度压力大 |
| L3 | 两页拆分 | 「项目体检」与「爆款案例」拆成两个页面/路由，各自有搜索分页；顶部互相跳转 | 信息架构最清晰 | 路由与导航改动最大，往返成本高 |
| L4 | 顶部 Tab | 同一页面用 Tab：「我们的项目体检」「爆款案例」；项目体检内用搜索 + 分页项目列表，选中后展示体检；案例库保留现有搜索/分页 | 分区最直观，扩展性好，改动中等 | Tab 状态需要维护；两区不能同屏对比 |

## 约束（所有方案适用）

- 项目选择不得再用下拉框；必须支持搜索 + 分页。
- 「我们的项目」与「他人案例」必须有明确标题/说明，不能混排。
- 保持大气整页布局，不做挤牙膏式向导。
- 项目体检仍为「事实层 + 强/中/弱分档」，不引入播放预测分数。
