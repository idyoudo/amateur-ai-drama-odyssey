## 强制约束（评估员一致）

- **G1**：GET 与 PUT 响应都不得出现明文 `api_key`；只返回 `api_key_set` + 服务端生成的末四位提示。PUT 中 `api_key` 缺失/空串 = 保留原值；只有显式 `api_key_clear: true` 才清除；掩码字面量（含 `…`/`••`/`***`）不得被写成新 Key。Key 不得进入日志、错误信息或 URL。`/models` 页面不得把 Key 回填进可提交字段。
- **G2**：只做加法迁移；启动顺序为 env 默认值 → DB 覆盖；不宣称加密（明文存储需明示）；不得在默认内存库下宣称持久化。

## 实现落地（2026-10-18）

- **G1**：`_public_model_config()` 输出 `api_key: ""` + `api_key_set` + `api_key_hint`；PUT 支持「空值保留 / 掩码忽略 / 显式清除」，并做长度与 URL 协议校验（非法 422）。
- **G2**：新增 `film/jobs/db.py::ModelConfig` 与 Alembic `0003_model_configs`；启动时 `_load_model_config()` 用 DB 覆盖 env 默认值；GET 返回 `persistence`（`durable=false` 时明确提示内存库重启丢失）。同时修正生成链路此前直读 env/传空配置的问题：`run_pipeline`、produce 的文本/图像适配器、供应商看板均改用合并后的 `_model_config`，使「已配置」真正生效。
- **前端适配**：SPA 模型页改用 `api_key_set` 判断已配置并显示末四位；`/models` 编辑页 Key 输入留空 + 提示，新增「清除已保存 Key」，保存仅发送非空 Key，并补上此前缺失的 `text` 类型（属于 G1 的编辑器适配，非完整 G3）。
- **验证**：`tools/verify_api.py` 新增 9 项断言（无明文、空值保留、掩码不覆盖、显式清除、落库、非法 URL），125/125 通过；跨进程重启测试确认 file DB 下配置保留。
