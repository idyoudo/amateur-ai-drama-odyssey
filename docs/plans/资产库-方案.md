# 资产库方案（角色 / 镜头）

> 目标：把原先只读的「资产展示页」升级为可检索、可查看详情、可跨项目复用、可导出的真正资产库。

## 一、范围

- **角色资产**：跨项目聚合定妆角色，展示所属项目、音色、锚点（正面/侧面/全身等）、状态、复用来源。
- **镜头资产**：跨项目聚合镜头，展示项目、集号/镜号、景别、角度、运镜、时长、角色、台词、提示词、状态、候选。
- **筛选与搜索**：项目、资产类型（全部/角色/镜头）、状态、关键词（角色名 / 镜头提示词、台词、景别、运镜）。
- **分页**：镜头按 offset 分批加载（每批 60），显示「已显示 X / 共 Y」。
- **详情**：角色详情（锚点、关联镜头、复用来源、复用到其他项目）；镜头详情（参数、台词、提示词、候选评分与选中状态）。
- **复用**：角色可复制到其他项目；同项目同名幂等，重复操作返回已存在角色。
- **导出**：按当前筛选导出 JSON 资产清单（含导出时间）。

## 二、数据与接口

- `characters.source_meta`（JSON）：记录复用来源（`copied_from`、`source_project_id`）；启动时幂等补列，Alembic `0006_character_source`。
- `GET /api/assets?project_id=&q=&status=&limit=&offset=`：角色全量（匹配筛选）+ 镜头分页；返回 `stats`（角色、镜头、已生成、已选定）、`character_total`、`shot_total`。
- `GET /api/assets/characters/{id}`：角色详情 + 关联镜头（最多 60）+ 关联镜头总数。
- `GET /api/assets/shots/{id}`：镜头详情 + 候选（`idx/score/selected/image_key`）。
- `POST /api/assets/characters/{id}/copy`：body `{target_project_id}`；跨项目复制，同名幂等。
- `GET /api/assets/export?project_id=&q=`：导出角色 + 镜头清单（上限 5000 条）。

## 三、页面结构

- 顶栏标题「资产库」，右侧「导出清单」。
- 统计卡：角色资产 / 镜头资产 / 已生成镜头 / 已选定镜头。
- 工具栏：搜索、项目筛选、类型筛选、状态筛选、重置。
- 角色区：卡片展示项目、姓名、音色、锚点、状态；点击打开详情。
- 镜头区：卡片展示项目、集/镜号、景别/运镜/时长/状态、角色或提示词；点击打开详情。
- 详情使用大尺寸弹窗（非分步向导），角色锚点与镜头候选以网格展示。

## 四、非目标

- 暂不做图片上传/替换与真实缩略图（当前无媒体存储与付费凭据）。
- 暂不做资产删除与版本历史。
- 暂无游标分页；使用 offset 分批加载。
