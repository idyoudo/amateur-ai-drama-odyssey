# 字幕与多语言本地化方案

> 目标：为每集提供可编辑的字幕轨，支持 SRT 导入导出、逐条校对、多语言翻译稿，服务红果/抖音/快手/YouTube 与出海分发。

## 一、数据模型

`subtitle_tracks`：

| 字段 | 说明 |
|------|------|
| project_id / episode_id | 所属项目与分集 |
| language | 语言代码（zh/en/ja/ko/es/pt） |
| source_language | 翻译稿的源语言 |
| status | 待翻译 / 翻译中 / 待校对 / 已完成 |
| cues | JSON 数组：`{start, end, text}`，单位为秒 |
| updated_at | 最近修改时间 |

唯一约束：同一项目、同一集、同一语言只能有一条字幕轨。

## 二、接口

- `GET /api/subtitles?project_id=&episode_id=`：字幕轨列表 + 支持语言/状态。
- `GET /api/subtitles/{id}`：单轨详情（含 cues）。
- `POST /api/subtitles`：新建空轨（同集同语言重复返回 409）。
- `POST /api/subtitles/import`：上传 SRT（base64），自动识别 UTF-8/GBK，解析后写入或覆盖该语言轨道，状态置为「待校对」。
- `PATCH /api/subtitles/{id}`：更新 cues / 状态 / 源语言。
- `POST /api/subtitles/{id}/duplicate`：复制为另一种语言的翻译稿，状态「待翻译」。
- `GET /api/subtitles/{id}/srt`：导出 SRT。
- `DELETE /api/subtitles/{id}`：删除。

## 三、页面

- 左栏：项目、分集、语言选择；字幕轨列表（语言、状态、条数、时长、更新时间）。
- 右栏：字幕编辑器（逐条开始/结束时间与文本、添加/移除、保存）、状态切换、导出 SRT、生成翻译稿、删除。
- 导入 SRT：选择文件后按当前项目/分集/语言解析并落库，自动选中该轨。
- 布局使用两栏整页（非向导），窄屏自动堆叠。

## 四、非目标

- 不做机器翻译：翻译稿复制原文并标记「待翻译」，由人工/后续翻译服务填充。
- 不做字幕烧录（burn-in）；交付仍以独立 SRT/字幕轨输出。
- 不接真实平台字幕 API。
