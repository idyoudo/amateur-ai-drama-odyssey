## 各票摘要

- **1 号 → L4**：Tab 标签即最强区分信号；两块各占整页；改动中等，可复用现有案例搜索/分页。风险：全量重渲染丢状态 → 把 tab、项目查询、选中项目、页码收敛进 HITS，Tab 常驻并带数量徽标。
- **2 号 → L3**：性质不同，拆页一眼分清；每页独占整页；路由成本低。风险：往返成本 → 主导航并列两项并互放跳转。
- **3 号 → L4**：改动最小，不动路由表与后端，`renderHits` 拆两段即可；风险：搜索输入失焦 → 局部重渲染或恢复焦点/光标，状态入 HITS。
- **4 号 → L4**：5 秒内理解两块性质不同；同页不动路由；两区独立演进。风险：默认只显示一个 Tab → Tab 常驻、带徽标、页头一行说明。
- **5 号 → L4**：案例与体检各自纵向生长，不牵动整体布局；L1 无限变长、L2 窄屏塌陷、L3 路由成本高。风险：状态丢失 → 统一状态并按 Tab 分域显示统计。

## 落地约束（取自候选与评审）

1. 顶部两个 Tab：**「我们的项目体检」** 与 **「爆款案例库（他人作品）」**，常驻并显示数量徽标。
2. 项目选择不得再用下拉框：改为搜索 + 分页项目表，选中行高亮，体检详情展示在表格下方。
3. 两区标题/说明必须明确区分「我们的项目」与「他人案例」。
4. 保持大气整页布局；体检仍为「事实层 + 强/中/弱分档」，不引入播放预测。
5. Tab、项目搜索、项目页码、选中项目、案例筛选与页码统一收敛到 `HITS` 状态；重渲染后恢复输入焦点。
