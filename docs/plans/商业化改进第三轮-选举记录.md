## 强制约束（评估员一致）

- **F1**：仅 hash 路由 + `hashchange`；未知路由渲染显式「未找到」并可回概览；不引入框架、不改页面结构、不把 token 写入 URL；登录后回到原本要去的路由。
- **F3**：骨架仅在真实请求进行中显示；失败必须展示服务端真实 `detail` 与「重试」；不得伪造进度或把 Mock 数据装扮成实时；超时用 `AbortController`，不得污染 GET 缓存与 401 登出链路。
- **F4**：只展示数据库已有字段（`progress/error_code/attempts/lease_epoch` 等），不合成进度；只接线既有 cancel/retry/resolve 端点；不改队列语义，保持 `max_parallel_writers = 1` 与幂等；流水线本轮保持同步；轮询在路由切换/标签页隐藏时停止。
