# 爆款分析与配方方案

> 目标：把「为什么火」变成可复用的产品能力：案例库、爆款公式、前 3 秒钩子、断章类型、项目爆款体检，并反哺新建项目与营销素材。

## 数据说明（重要）

公开检索未获得《穷骨荒神》《招惹少年》《横刀镇妖》可核验的播放量数字。模块中：

- `play_count` 留空，标注「未公开 / 未核验」，不做数字编造；

## 三部案例的结构拆解

### 穷骨荒神（玄幻/逆袭）
- 配方：**极端反差 / 打脸**
- 前 3 秒：被判定「穷骨/废骨」，当众受辱/逐出，最低点开局
- 推进：荒神残魂/机缘 → 首次反杀 → 更强对手 → 身世与力量来源半揭
- 断章：绝境反转
- 为什么火：低起点强代入 + 成长确定性 + 连续打脸；观众无需理解复杂设定，只看主角翻盘。

### 招惹少年（言情/禁忌）
- 配方：**禁忌情感 / 招惹**
- 前 3 秒：主动招惹危险少年，抛出「你确定要招惹我？」式危险信号
- 推进：试探 → 占有/保护 → 身份秘密 → 误会/决裂 → 关系曝光
- 断章：身份暴露
- 为什么火：禁忌关系持续张力，CP 拉扯提供高频情绪回报，每集一个可讨论节点。

### 横刀镇妖（玄幻/镇妖）
- 配方：**镇妖 / 单元怪**
- 前 3 秒：妖祸降临、一刀镇妖，先给结果再讲原因
- 推进：单元怪 → 更强妖王 → 封印/身世 → 更大妖祸
- 断章：新敌登场
- 为什么火：单元怪稳定节奏 + 升级体系长期目标 + 竖屏动作奇观。

## 产品调整

1. **新建项目**：格式建议中直接显示推荐爆款配方与前 3 秒钩子类型（按题材映射）。
2. **营销素材**：文案区展示爆款配方，标题/钩子围绕配方生成。
3. **项目爆款体检**：按 6 个维度评分（钩子/冲突密度/断章/情绪回报/标题封面/视觉奇观），给出 S/A/B/C 与逐项改进建议；项目详情顶栏一键进入。
4. **爆款分析页**：案例库、配方库、钩子库、断章库；案例可新增/编辑（拿到真实数据后可补播放量与核验状态）。

## 接口

- `GET /api/hits`：案例 + 配方库
- `GET /api/hits/playbook`：配方/钩子/断章字典
- `GET /api/hits/{id}`：案例详情
- `POST/PATCH/DELETE /api/hits`：维护案例（可补真实数据）
- `GET /api/dramas/{id}/hit-check`：项目爆款体检

## 非目标

- 不把启发式评分伪装成真实播放量预测。
- 不抓取平台后台数据；真实数据需平台授权或用户导入。
- 不复制具体作品剧情，只抽象结构配方。
