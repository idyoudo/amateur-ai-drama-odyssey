# UI 进阶候选（大气 / 优雅）—— 待 5 人选举

> 前提：v4 Editorial Cinematic 已上线（衬线展示体 + 大留白 + 近单色）。本文件提出 5 项进阶候选，由 5 人选举裁决是否吸纳。

| 编号 | 候选 | 做法 | 预期收益 | 风险 |
|------|------|------|----------|------|
| E1 | **全幅 Hero（概览首屏）** | 首屏做成通栏「电影片头」式：超大衬线标题 + 克制的氛围渐变/细线母题 + 滚动后收为常规标题 | 第一印象的「大气」最直接 | 首屏信息密度下降；需控制高度避免滚动浪费 |
| E2 | **项目卡电影感封面** | 项目卡顶部加 16:9 封面区：克制的渐变色阶 + 片名排印（无图片时也像海报） | 让「作品」成为视觉主角，像流媒体片库 | 渐变滥用会显廉价；需统一色板与排印规则 |
| E3 | **模块页编辑式大标题** | 项目/资产/模型等页面标题从 19px 升到 34–40px 衬线，副标题/操作在下方或右侧 | 层级更戏剧化、更像出版物 | 长标题换行；需统一断行策略 |
| E4 | **深色主题同等级打磨** | 把深色从「变量覆盖」升级为与浅色同级的完整主题（表面层级、边框、强调、封面） | 夜间/审片场景可用；品牌完整度 | 维护双主题成本 |
| E5 | **动效与微交互** | 页面切换淡入上移、卡片悬停揭示、数字滚动、步骤条过渡；遵守 prefers-reduced-motion | 提升「高级感」的体感 | 过度动效反而廉价；需克制 |

## 评估维度

是否真正提升「大气/优雅/现代化」；是否契合好莱坞级制作工具；改动成本与风险；是否可能引入廉价感；可回退性。
