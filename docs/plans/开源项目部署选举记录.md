## 二、五票结论

### 1. 产品 / 内容负责人

部署：ToonFlow、MoneyPrinterTurbo、NarratoAI。
理由：ToonFlow 直接对标短剧/漫剧全流程；MoneyPrinterTurbo 社区最大、最快出片；NarratoAI 补足解说二创。
不部署但展示：AI-Youtube-Shorts（CLI）、ShortGPT（停更）。

### 2. 运维 / SRE

部署：MoneyPrinterTurbo、NarratoAI、AI-Youtube-Shorts、ToonFlow。
理由：MPT 官方镜像免构建；NarratoAI 能力互补但构建重；AI-YT 无常驻进程；ToonFlow 最轻但与 retail 的 toonflow 功能重复，排末位。
不部署但展示：ShortGPT、MoneyPrinterPlus、GPU-only 项目。

### 3. 安全 / 合规

部署：ToonFlow、MoneyPrinterTurbo、NarratoAI。
理由：三者均为 MIT、活跃维护；主要缺口是默认无鉴权，必须在反向代理层加认证。
不部署但展示：AI-Youtube-Shorts（版权风险）、ShortGPT/MoneyPrinterPlus（停更）、GPU-only 项目。

### 4. 成本 / 资源

部署：ToonFlow、MoneyPrinterTurbo、AI-Youtube-Shorts、NarratoAI。
理由：ToonFlow 常驻约 131MB；MPT 用预构建镜像；AI-YT 无常驻；NarratoAI 最重、排末位。
不部署但展示：停更项目与 GPU-only 项目。

### 5. 创作者体验

部署：ToonFlow、MoneyPrinterTurbo、NarratoAI。
理由：ToonFlow 最贴短剧创作；MPT 适合宣发预告试水；NarratoAI 二创解说强。
不部署但展示：AI-Youtube-Shorts（无 Web UI）、停更项目、GPU-only 项目。

## 四、最终裁决

**部署 3 个：ToonFlow、MoneyPrinterTurbo、NarratoAI。**

- 未用满 5 个名额：受 2 vCPU / 7.2GB / 40GB 约束，3 个已覆盖「短剧全流程 / 一键短视频 / 解说二创」三类核心场景，继续增加只会争抢资源。
- 所有工具统一走 Caddy 反向代理 + HTTP Basic Auth，不直接暴露应用端口。
- ToonFlow 端口 3000 → 18588；MPT WebUI 8501 → 18501、API 8080 → 18502；NarratoAI 8501 → 18503。
- 每个应用设置内存上限；视频转码串行使用，避免与 AADO/retail 争抢。

## 六、风险与后续

| 风险 | 处置 |
|---|---|
| ToonFlow 无内置鉴权 | 网关强制 Basic Auth；后续可换 HTTPS |
| MPT / NarratoAI 保存模型 Key | 仅部署者可见；文档提示不要在共享环境填生产 Key |
| NarratoAI 镜像重、构建慢 | 单次构建；失败不阻塞其余两个 |
| 2 vCPU 转码并发 | 文档要求一次只跑一个生成任务 |
| 40GB 磁盘 | 构建后清理 builder cache；产物定期清理 |
