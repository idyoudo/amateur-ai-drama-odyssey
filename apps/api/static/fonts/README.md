# 自托管字体（D1）

本目录为拉丁子集 woff2，`font-display: swap`。三款字体均为 SIL Open Font License 1.1（OFL），
可随产品分发，但须保留许可声明。

| 字体 | 来源 | 许可 |
|------|------|------|
| Inter | https://github.com/rsms/inter | OFL-1.1 |
| Instrument Serif | https://github.com/Instrument/instrument-serif | OFL-1.1 |
| JetBrains Mono | https://github.com/JetBrains/JetBrainsMono | OFL-1.1 |

**中文字形不在本目录**：正文/标题的中文回退到系统 PingFang SC / Songti SC（见 `app.css` 的 `--sans/--serif`）。
如需统一中文观感，可另行自托管思源宋体/黑体的子集，但会显著增加体积。

OFL 许可证全文：https://openfontlicense.org/open-font-license-official-text/
