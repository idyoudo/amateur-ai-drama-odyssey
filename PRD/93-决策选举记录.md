# 决策选举记录（附录）

> 本附录记录 Amateur AI Drama Odyssey（`amateur-ai-drama-odyssey`）「好莱坞级 AI 短剧」PRD 中**争议选项的裁决过程与结果**。规则：每项决策由 5 名独立评估员背对背投票（多数决；平票进入第二轮决选，7 名新评估员），每位评估员必须给出理由、最大风险与缓解措施。**结论对本 PRD 具有约束力**，相关模块的规格、NFR 与验收指标必须服从。

- 第一轮：6 项决策 × 5 名评估员 = 30 次独立评估
- 第一轮决选（D2 平票）：7 名新评估员
- **第二轮：8 项决策 × 5 名评估员 = 40 次独立评估**（D7–D14，结果同样具有约束力）
- 投票者被明确要求：独立判断、不迎合他人、不因某方案"更流行"而选择它

## 二、逐项记录

### D1 主交付画幅与形态

- **胜出**：A —— 2.39:1 母版；16:9 平台版；9:16 竖屏衍生版
- **票型**：A 3 票（置信度和 2.22）/ B 2 票（1.27）/ C 0 票
- **异议方（B：16:9 为主）核心理由**：主流生成模型的训练分辨率偏 16:9，原生生成伪影最少；2.39 母版回到 16:9 必须补画面，而 16:9 → 2.39 只损失上下边，方向更安全。
- **胜方核心理由**：宽银幕是最直接的"电影感"签名；向下裁切优于向上扩画；一次拍摄多端分发是成熟工业流程。
- **最大风险（所有评估员共同指出）**：**9:16 衍生版质量塌陷**——从 2.39 裁到 9:16 会损失约 60–70% 画面宽度，人物站位与关键动作极易出框。
- **强制缓解措施**（写入 PRD）：
  1. 生成阶段即执行**多画幅安全框**：所有关键表演与叙事信息收在中心 9:16 安全区内，两侧仅承载氛围；
  2. 关键竖屏桥段**用 9:16 原生重生成**，不靠裁切；
  3. 9:16 独立质检关卡（人脸一致性、运动连贯、字幕不遮挡），不通过则重做该镜头；
  4. 以 16:9（open gate）最高分辨率作为**唯一生成母版**，2.39 与 9:16 从同一素材派生，禁止为某单一画幅重复生成。

### D2 单集时长与集数结构（含决选）

- **首轮**：A 2 票（1.38）/ B 1 票（0.66）/ C 2 票（1.38）→ **A 与 C 平票**，进入决选
- **决选**：A 6 票（4.24）/ C 1 票（0.72）→ **A 胜出**
- **胜出**：A —— **每集 22–45 分钟，6–12 集**，含 cold open 与 act breaks
- **异议方（C：60–90 秒 × 80–100 集）核心理由**：AI 在 60–90 秒量级才稳定；短集可在第 8–12 集就拿到留存数据并回改；单位分钟成本更低、失败半径按季封顶。
- **胜方核心理由**：
  1. **叙事容量**：cold open 与 act breaks 才能承载人物弧光与三幕结构；60–90 秒单元只能承载钩子；
  2. **工程可落地性（决定性）**：单项目上限 50 集，80–100 集直接越限；跨集一致性风险随集数**线性放大**，而跨集一致性是本项目已认定的第一交付风险；
  3. **门禁经济性**：五节点人工终审按集发生，6–12 集约 30–60 次门禁事件，80–100 集则需 400–500 次，人工终审会退化为签章流水线，使 D6 的质量机制失效；
  4. **成本结构**：每集固定开销（片头、AI 标识、母版导出、多规格、审看上下文切换）在 22–45 分钟单元上被摊薄，在 60–90 秒单元中占比 25–35%，且这部分不计入平台"有效播放时长"分账；
  5. **不可逆性**：A → C 是廉价降级（重剪/重构/重混，不新增生成），C → A 无法升维。
- **最大风险**：单集 22–45 分钟意味着**一集即一个大失败单元**，且 AI 在此长度下的长程一致性尚无先例。
- **强制缓解措施**（写入 PRD）：
  1. **先导集闸门**：先只做 Ep1（含竖屏衍生单元）完整走完五节点门禁，通过才解锁后续集数；
  2. **分块 go/kill**：首季锁定 6 集 × 22–30 分钟（下限配置），每 2–3 集一个 pod，pod 后重做一次 go/kill；
  3. 把「集」定义为**组装与质检单元而非生成单元**：生成切到场景/镜头级，返工按镜头区间重跑，不整集重做；
  4. **关键镜头混合式制作**：AI 生成 + 人工精修关键表演与合成（对标已上线的 AI 季播剧做法）。
- **落选方案诉求的低成本覆盖**：9:16 衍生版按 act break 切成 60–90 秒竖屏单元（不新增生成，仅重剪/重配/重混/重新挂标识），用于平台留存测试与早期反馈；短形式能力（超长剧集 + 超短单集产能）仍保留为**衍生层**能力，不为它牺牲母版管线。

### D3 声音交付规格

- **胜出**：A —— 立体声母版（EBU R128 −23 LUFS / ≤−1 dBTP）+ 5.1 环绕版可选
- **票型**：5:0（置信度和 3.68）
- **最大风险**：①「可选 5.1」沦为名义能力，真被要求时从上混产生相位与声场伪影；② 单一 −23 LUFS 母版与流媒体（约 −14 LUFS）、院线（约 −27 LKFS 对白门控）口径不同，可能被下游 QC 拒绝。
- **强制缓解措施**：
  1. 混音阶段即锁定 **5.1 声道布局与 stem 结构**（对白/音乐/音效分轨），5.1 仅在**存在真实分轨且通过下混兼容性测试**（中心声道折返 −3 dB、相位与单声道兼容）时交付，否则显式降级为立体声并在交付单标注；
  2. 以 −23 LUFS / ≤−1 dBTP 为**唯一归档母版**，由它自动派生平台响度版本（流媒体约 −14 LUFS、对白门控约 −27 LKFS）并统一跑自动 QC；
  3. 交付前自动 QC 强制项：响度、真峰值、下混 null 对比、相位检查。

### D4 色彩与母版管线

- **胜出**：A —— ACES 管线 + Rec.709 SDR 主母版 + HDR10 可选交付
- **票型**：5:0（置信度和 4.01）
- **最大风险**：**IDT 误配的系统性偏色**。AI 生成素材没有相机元数据，其观感多为已烘焙的显示参考（sRGB/Rec.709）；若被当作场景参考线性素材处理，会出现反差、饱和与肤色偏移，而且问题常在交付前才暴露。
- **强制缓解措施**：
  1. 为每个生成模型/来源**锁定固定 IDT 与输入变换**并文档化；
  2. 用标准色卡与灰阶测试图建立验收基线，先在 3–5 个 hero shot 上做 ACES→Rec.709 往返一致性测试，通过后全量铺开；
  3. **HDR10 严格隔离为独立下游 pass**，只在收到明确交付需求时启动；
  4. 始终保留一条**纯 Rec.709 降级路径**，色彩配置版本化且可回滚。

### D5 帧率与运动质感

- **胜出**：A —— 24fps 电影感（180° 快门运动模糊）+ 48fps 可选
- **票型**：5:0（置信度和 3.86）
- **最大风险**：24fps 在快速横摇、追逐与动作段落出现**频闪/抖动（judder）**；平台强制转 30fps 会产生不均匀帧节奏。
- **强制缓解措施**：
  1. 锁定 24fps 唯一时间线与统一运动模糊参数；对高速运动镜头在 shot list 中单独标注（必要时以 48fps 生成后再做快门角重映射统一到 24fps 母版）；
  2. 逐镜头做 judder 检查，限制最大摇摄角速度；
  3. 交付同时提供 24fps 母版与经光流重定时的 48fps 兼容版，**避免平台自行二次转码**；
  4. QC 清单加入运动抖动与帧节奏一致性抽检项。

### D6 质量门禁的最终裁决者

- **胜出**：A —— AI 提议 + 人工终审（五节点：剧本、定妆、分镜、成片、母版）
- **票型**：5:0（置信度和 4.10）
- **最大风险**：**人工终审退化为橡皮图章**（档期压力与审批疲劳导致对着 AI 的"通过"建议直接签字），门禁形式化、责任稀释。
- **强制缓解措施**：
  1. 每个节点绑定**二元化验收清单与唯一署名审批人**，无署名即视为未通过；
  2. **强制结构化决策记录**：通过/驳回必须带理由码；对「零缺陷」的通过必须给出书面理由；
  3. 对已放行节点做**固定比例回溯抽检**，偏差计入审批人质量档案；
  4. 每个节点设**候选审片人与并行审片队列**，用 SLA 消化排期压力，避免把拥堵转化为放水；
  5. AI 的异议（建议驳回项）**不得被静默覆盖**，覆盖需留痕。

## 三、第二轮记录（D7–D14）

> 第二轮共 8 项决策 × 5 名独立评估员 = **40 次独立评估**。本节逐项记录胜出方案原文、票型、异议方核心理由、胜方核心理由、最大风险与强制缓解措施。**第二轮材料未提供置信度与逐字引文，故本节不记录这两项，也不得据本节反推。**

### D7 首季单集时长（OD-01）

- **胜出**：A —— **6 集 × 30 分钟（约 180 分钟），先导集验证后分块放行**
- **票型**：5:0（全体一致，无正式异议方）
- **异议方核心理由**：无正式异议票；5:0 一致项的风险由全体评估员共同标注（见「最大风险」）。
- **胜方核心理由**：
  1. **形态门槛硬约束**：Emmy Limited Series 要求总时长 ≥150 节目分钟（B-89），**6 集 × 30 分钟 ≈ 180 分钟**是能稳住该门槛且不靠硬凑的配置；22 分钟档合计约 132 分钟会直接低于门槛。
  2. **成本与叙事容量平衡**：30 分钟档在长形式叙事容量（cold open + act breaks）与单位成本之间取中；45 分钟档在首季会放大单集失败半径与生成成本。
  3. **降低锁死风险**：先导集验证后分块放行，使「30 分钟」可在拿到实测数据后再确认或回退，而不是立项即不可逆。
  4. **终集弹性**：允许季终集在总时长内上探 45 分钟承载收束，不改变其余集的 30 分钟基准。
- **最大风险（所有评估员共同指出）**：① **30 分钟 × 6 集在 AI 长程一致性上仍无先例**，跨镜头漂移可能在 pod 2 之后才暴露，届时返工价最贵；② **分块放行被形式化**——若 pod go/kill 只走流程不看数据，等于把整季一次性押上；③ 季终集上探 45 分钟会额外拉长生成与门禁周期，挤压母版与交付窗口。
- **强制缓解措施**（写入 PRD）：
  1. **先导集验证 + 三项实测数据**：先导集五门禁全部通过，且必须产出①**可交付母版分钟成本**、②**镜头级重生成率**、③**跨镜头漂移分位**，才授权 pod 1；
  2. **未出分位数不得进入 pod 2**：跨镜头漂移分位数是 pod 2 的硬性前置条件，缺该数据即阻断放行，不允许以「进度紧」为由跳过；
  3. **22 分钟备剪版作为降级闸门**：先导集同时产出 30 分钟版与 22 分钟备剪版（不新增生成），若 30 分钟版在一致性/成本/节奏上不达标，立即降级为 22 分钟档并重估形态门槛（B-89）对策；
  4. **季终集上探 45 分钟需显式批准**：上探须在总时长预算内，并同步更新排期、预算与门禁资源，不得默认执行；
  5. 时长锁定为 **pod 复盘后的显式决议项**（见第五节 OD-01），pod 复盘数据不足以支撑时维持 30 分钟基准但保留回退权。

### D8 是否自建开源推理栈（OD-02）

- **胜出**：A —— **不自建，先把云 API 链路打透**（成本靠错峰/缓存/降级控制）
- **票型**：4:1
- **异议方（主张部分自建）核心理由**：自托管 Apache-2.0 组件（Wan 2.x 视频、LatentSync 口型、CosyVoice TTS、ACE-Step 音乐）可压低单位分钟成本；长期看自有推理资产不受供应商限流与涨价影响，且权重与版本可完全固定，有利于一致性复现。
- **胜方核心理由**：
  1. **风险收益不对称**：自托管的收益是**未来的单位成本**，代价是**当下的运维与质量风险**（GPU 运维、吞吐调度、模型版本与权重管理、故障自愈），后者会直接侵蚀首季交付能力；
  2. **质量风险高于收益**：自托管组件与云 API 在画质/口型/音质上的差距无实测基线可依，首季不应把交付质量押在未评测路径上；
  3. **成本有更廉价的手段**：错峰调度（约五折）、内容寻址缓存、分级路由与降级矩阵可先拿到大部分成本收益，且不引入运维负债；
  4. **保留升级路径**：C（仅口型/TTS 自托管）作为第二季成本复盘评估项保留，届时用首季真实成本数据与质量基线判断，避免现在凭估算决策。
- **最大风险**：**单一云链路依赖**——供应商限流、涨价、能力下线或区域故障会直接阻塞生产；同时错峰与缓存若未真正落地，成本目标会落空。
- **强制缓解措施**（写入 PRD）：
  1. **降级矩阵与供应商切换**：按能力档位预置备用模型（高价→经济→减候选或缩短时长），降级不改变叙事结构，且强制记录降级原因与批准人；
  2. **成本控制三件套强制计量**：错峰排期、内容寻址缓存复用、分级路由（Draft→升清）必须各有可查询的节省量与命中率指标，不能只作为口号；
  3. **供应商与配额治理**：登记限流阈值、配额与联系方式，对限流与预算熔断做显式处理而非静默失败；
  4. **自托管评估保留且数据化**：口型/TTS 自托管评估推迟到第二季成本复盘，评估须给出成本/质量/运维三项结论（含首季真实单位分钟成本对照）。

### D9 关键镜人工精修产能（OD-03）

- **胜出**：C —— **混合：关键镜/角色脸自建，量镜（天空替换、去杂物、粒子）外包**
- **票型**：4:1
- **异议方（主张全自建或全外包）核心理由**：全自建会让人工精修成为产能瓶颈、拉长单集周期；全外包则成本更可预测、峰值产能弹性更好，且外包团队在同一量镜类型上更熟练。
- **胜方核心理由**：
  1. **按一致性敏感度切分**：关键镜与角色脸承载角色一致性与表演可信度，是本项目第一交付风险所在，**不能外包**——外包会引入第二套审美与第二套人物理解，正是漂移的来源；
  2. **量镜标准化程度高、可外包**：天空替换、去杂物、粒子属于模板化、可量化验收的工作，用外部产能换速度，性价比最高；
  3. **混合保住主流程**：自建关键镜使角色资产与锁定版本留在内部流程，外包只处理不触碰角色核心的层。
- **最大风险**：**外包件回灌断裂**——外包交付的层与内部资产族脱节（不同分辨率/色彩空间/命名/版本），在合成阶段才发现对不上，导致重建与返工；同时外包的一致性验收标准若缺失，量镜质量会污染成片观感。
- **强制缓解措施**（写入 PRD）：
  1. **外包件必须回灌同一资产族**：外包产物按统一命名、分辨率、色彩空间与版本谱系登记，挂回母版谱系，禁止以「外部文件」形式游离在资产族之外；
  2. **统一质检与验收清单**：外包件进入与自建件相同的质检口径（画幅安全区、色彩一致性、无坏帧/闪帧、透明通道与边缘质量），不通过即退回；
  3. **边界显式化**：外包范围仅限量镜类别，**角色脸与关键镜不得进入外包清单**，边界写入任务派发与验收单据；
  4. **精修投入比例记录**：按镜头类别记录自建/外包的工时与成本，供 pod 复盘与后续裁决使用（对应 M14 门禁人力与镜头级成本口径）。

### D10 影院 DCP 通道（OD-04）

- **胜出**：C —— **只做影展/平台投递包，不自建 DCP**
- **票型**：5:0（全体一致，无正式异议方）
- **异议方核心理由**：无正式异议票；风险由全体评估员共同标注。
- **胜方核心理由**：
  1. **技术门槛与成本不匹配**：DCP 需 **J2K + MXF 封装 + XYZ 色彩空间 + KDM 密钥**，涉及专用工具链、校验与影院调试，成本高、周期长；
  2. **首季未必上影院**：影展投递的实际需求可用 **ProRes 母版**满足，多数影展/平台接受高质量 ProRes 投递包；
  3. **避免过早资本化**：自建 DCP 通道属于只有在院线路线确认后才值得投入的能力，过早建设会占用首季资源且可能闲置；
  4. **外部服务商路径足够**：真需要 DCP 时按次外包，成本可预测且不引入常设工具链维护负担。
- **最大风险**：**临时性 DCP 需求打乱节奏**——若影展入选或院线窗口突然要求 DCP，外包排期与调试可能来不及；同时若对外承诺了 DCP 而未交付，会造成交付口径失约。
- **强制缓解措施**（写入 PRD）：
  1. **交付口径显式排除**：交付承诺只含 ProRes 母版与影展/平台投递包，**不承诺 DCP**，并在交付单与对外材料中明确标注；
  2. **保留 ProRes 母版作为可转制基础**：母版保持足够位深与分辨率（满足后续 J2K/XYZ 转制的输入要求），不因不做 DCP 而降规格；
  3. **外部服务商预案**：预置至少一家 DCP 服务商与其交付周期/成本口径，需求出现时按次委托，并保留人工 QA（含 KDM 与影院放映校验）；
  4. **影展技术规格核验**：投递前逐个核验目标影展/平台的规格要求（编码、码率、音频布局、字幕形式），不接受「通用投递包」假设。

### D11 多语言本地化（OD-05）

- **胜出**：A —— **中文优先，英语作为第二语种在首季同步准备**
- **票型**：5:0（全体一致，无正式异议方）
- **异议方核心理由**：无正式异议票；风险由全体评估员共同标注。
- **胜方核心理由**：
  1. **母语优先保质量**：中文为首季创作与表演语言，剧本、对白与口型均以中文为基准，避免为多语同时创作而稀释质量；
  2. **英语同步准备成本低、收益明确**：英语是平台分发与影展投递的最低必要第二语种，**在结构上**预留本地化位（不新增母版）比事后回改便宜得多；
  3. **结构预留而非内容重复**：stem 分离与字幕位属于**结构与素材层**能力，先期做好即可在多语版本派生时零重复生成；
  4. **合规硬要求**：中国境内每集须有 AI 提示标识，该标识属于母版级要素，必须在一开始就纳入而不作为后期补丁。
- **最大风险**：① **英语版本被误当作第二个母版**，导致双母版、双 QC 与成本翻倍；② 多语配音与字幕若在**锁定画面后**才插入，会出现口型对不上、字幕遮挡安全区、AI 标识位置冲突等问题；③ 本地化位预留若只写在文档里而未落到素材结构，等于没有预留。
- **强制缓解措施**（写入 PRD）：
  1. **单一母版原则**：英语版本只能由中文母版**派生**（字幕 + 配音，复用 stem），不得产生独立母版；出现第二母版即判配置错误并告警；
  2. **结构预留前置到混音与分镜**：混音阶段即锁定 stem 结构（对白/音乐/音效分离），分镜阶段预留字幕安全区，使本地化不触碰画面母版；
  3. **AI 提示标识母版级固化**：中国境内每集在母版即带 AI 提示标识，多语派生版本继承并对标识文案做本地化，不得因本地化而丢失标识；
  4. **本地化版本纳入交付单**：语言、字幕形式、配音状态与标识状态写入交付单与元数据，未标注的本地化版本不得对外交付。

### D12 Demo 交付形态

- **胜出**：A —— **规范合规模拟母版**：三画幅 24fps 动画分镜 + 真实 **−23 LUFS / ≤−1 dBTP** 音频母版 + **机器可读 QC 报告** + **自包含仪表盘**
- **票型**：5:0（全体一致，无正式异议方）
- **异议方核心理由**：无正式异议票；风险由全体评估员共同标注。
- **胜方核心理由**：
  1. **可自证**：Demo 的价值在于**在无 GPU、无 ffmpeg、无付费凭据**的条件下，仍能自证「规范与门禁是可机检的」，而不是靠陈述；
  2. **规范合规而非视觉炫技**：三画幅 24fps 动画分镜直接检验多画幅安全框与帧率口径；真实响度母版检验 −23 LUFS/≤−1 dBTP；机器可读 QC 报告与自包含仪表盘让门禁结论可复核、可追溯；
  3. **零外部依赖可复现**：不依赖付费 API 与 GPU，使 Demo 可被任何人重复运行验证，避免「只有作者机器上能跑」；
  4. **为后续模块提供契约样本**：QC 报告与交付单的字段结构成为 M10/M11/M12 的落地样板。
- **最大风险**：**代理样片被误用/误读为成片母版**——Demo 的画幅、音频与 QC 结果看起来像正式母版，容易被引用为「已达成的交付能力」，进而对外承诺未实现的能力；此外程序化合成的 Demo 音频可能掩盖真实混音链路的缺陷。
- **强制缓解措施**（写入 PRD）：
  1. **强制代理标识**：Demo 类产物必须在元数据与画面上标注「**代理样片 / PROXY — NOT A DELIVERABLE MASTER**」，不得冒充成片母版（派生 EL-16）；
  2. **交付单显式声明**：Demo 的交付物须在交付单中声明其为代理样片，不构成母版、不进入母版门禁结论；
  3. **QC 报告标注适用边界**：机器可读 QC 报告须写明其检验对象为代理样片，结论不得直接引用于正式交付验收；
  4. **真实链路复验**：Demo 通过不代表正式链路通过——正式音频/口型/混音链路上线后，须重跑同一 QC 口径并记录差异。

### D13 先导集题材

- **胜出**：A —— **都市悬疑/逆袭**
- **票型**：5:0（全体一致，无正式异议方）
- **异议方核心理由**：无正式异议票；风险由全体评估员共同标注。
- **胜方核心理由**：
  1. **一致性负担最低**：现代实景与当代服装无需大量世界构建与服装/道具考据，角色形象与场景的跨镜头一致性更容易维持，正好对准本项目第一交付风险；
  2. **对白密集覆盖核心难点**：都市悬疑/逆袭以对话推进，天然覆盖**表演、口型、正反打**这三类最难的能力点，使先导集验证具有代表性；
  3. **动作需求可控**：动作由**一场近身冲突**覆盖，既检验动作/快摇与 judder 处理，又不把先导集拖入大场面 VFX 的高成本区；
  4. **验证性价比高**：把有限的先导集预算投入到最难且最高频的能力上，而不是最贵的场面上。
- **最大风险**：① **题材同质化**——都市悬疑/逆袭供给密集，差异化不足会影响平台与观众判断；② **对白密集即口型密集**，口型与语音若未达标，缺陷会在先导集被最密集地暴露；③ 近身冲突的动作镜是 judder 与物理可信度的高风险点，处理不当会显得廉价。
- **强制缓解措施**（写入 PRD）：
  1. **口型与语音先行验证**：先导集把口型/配音作为重点验证对象，对白密集镜次须过表演与口型质检，未达标不得进入成片门禁；
  2. **正反打与视线连续性纪律**：对白场景严格执行轴线与视线方向规则，越轴作为告警项处理并记录；
  3. **近身冲突镜单独标注**：动作镜纳入快摇/动作镜清单，做 judder QC 与运动模糊一致性检查；
  4. **差异化显式设计**：题材选择不等于放弃差异化，剧本阶段须给出与同类题材区隔的设定与人设，避免落入同质化。

### D14 Demo 音频母版形态

- **胜出**：A —— **程序化合成四层总线**（对白占位/音乐和弦/音效脉冲/环境噪声）+ **四路 stem** + **立体声母版**
- **票型**：5:0（全体一致，无正式异议方）
- **异议方核心理由**：无正式异议票；风险由全体评估员共同标注。
- **胜方核心理由**：
  1. **无需 TTS 即可验证结构**：用程序化合成即可产出四层总线，从而验证**四层结构与四路 stem**的定义是否正确，而不必先解决 TTS 与配音能力；
  2. **直接检验响度合规**：合成素材同样可以做成真实的 −23 LUFS / ≤−1 dBTP 立体声母版，使响度与真峰值门禁可机检；
  3. **与 D3/EL-06/EL-07 口径一致**：四路 stem 结构正是混音阶段即锁定 stem 的落地形态，Demo 因此不是孤立的演示而是正式口径的样本；
  4. **零付费依赖**：不依赖任何付费音频服务，保证 Demo 可复现。
- **最大风险**：① **合成音频掩盖真实问题**——程序化对白占位不含真实语音，无法暴露口型/对白清晰度/对白门控响度等真实混音问题；② **合成动态范围失真**，使真实素材下混与峰值表现与 Demo 不一致；③ 误把 Demo 的四层结构当成正式混音的最终层数定义（层结构可能随创作演进）。
- **强制缓解措施**（写入 PRD）：
  1. **Demo 音频标注为代理**：Demo 音频母版按代理样片标注，不得作为正式母版或交付件（与 D12/EL-16 一致）；
  2. **真实链路复验同一口径**：接入真实对白/配音与音乐后，须用同一 QC 口径（响度、真峰值、下混 null 对比、相位、单声道兼容）重跑并记录差异；
  3. **层结构留可扩展余地**：四层总线作为 Demo 与首季的基准结构，允许在正式混音阶段按创作需要细分或扩展，但**四路 stem 与 5.1 声道布局的锁定要求不变**；
  4. **下混路径同 Demo 同规则**：立体声母版由 stem 下混产出，沿用中置/环绕 −3 dB 与 LFE 不下混的纪律，避免 Demo 与正式链路口径分叉。
