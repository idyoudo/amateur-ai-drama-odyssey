# Amateur AI Drama Odyssey · 好莱坞级 AI 短剧 项目总览（L1）

- **项目名称**：Amateur AI Drama Odyssey（代号 `amateur-ai-drama-odyssey`，缩写 AADO）
- **宿主平台**：Retail Trading Odyssey（RTO）——文中「RTO 现状」「RTO 存储」等指宿主平台与既有实现
- **首季包型**：6 集 × 30 分钟（D7 决议）｜**首集**：《回声》（都市悬疑，D13 决议）

> 本文档是整套 PRD 的 L1 总览，规则见 [README.md](README.md)；对标与依据见 [99-业界对标与调研.md](99-业界对标与调研.md)、[91-影视技术规格与交付标准.md](91-影视技术规格与交付标准.md)、[92-好莱坞制作流程对标.md](92-好莱坞制作流程对标.md)；**争议决策的裁决结果见 [93-决策选举记录.md](93-决策选举记录.md)（具有约束力）**。

## 一、项目背景与问题

### 1.1 现状

宿主平台 RTO 已建成一条可运行的 AI 短剧流水线：小说/文字或图片 → 改编剧本 → 分镜 → 文生图关键帧 → 图生/文生视频 → 多角色 TTS → ASR 字幕 → FFmpeg 合成 → 审核 → 导出。并以独立容器 + iframe 接入 Toonflow、LumenX 两个开源创作工作台。

**它现在能出片，但出不了"电影"。** 与好莱坞工业标准的差距不是画质参数，而是**流程与规范**：没有剧本开发文档序列、没有选角与定妆确认、没有分镜与 previz、没有镜头语言控制、没有分层声音设计、没有剪辑时间线、没有调色与母版管线、没有影视级 QC 与交付规格。

### 1.2 关键问题（按影响排序）

| 问题 | 现状表现 | 好莱坞对应环节 |
|------|----------|----------------|
| 剧作不是"开发"出来的 | 直接改编成分集剧本，无 logline/treatment/beat sheet 与多稿修订 | Development |
| 无选角与定妆确认 | 角色只有字段与文本描述，无定妆图确认流程 | Casting / Pre-production |
| 无镜头语言控制 | 固定 6 镜、无景别/焦距/运镜结构化控制、硬切 | Cinematography |
| 无 previz 与分镜脚本 | 无 storyboard/animatic，直接生成 | Storyboard / Previz |
| 无表演层 | 只有 TTS 与口型缺失，无表演设计与 ADR | Performance |
| 无声画设计 | 单曲循环 BGM、无音效/环境声/Foley、无混音标准 | Sound Design / Mix |
| 无剪辑 | 按镜顺序拼接，无时间线与节奏设计 | Editorial |
| 无调色与母版 | 直接输出 1280×720 H.264，无色彩管理与母版 | DI / Mastering |
| 无交付规格 | 无多规格、无 QC、无交付单 | Delivery / QC |
| 质量无门禁 | 只有任务成功/失败，无署名终审 | Quality Control |
| 成本与权利不受控 | 无预算硬约束、无权利链台账 | Legal / Production |

## 二、愿景与终极目标

**一句话愿景**：把一部长篇小说交给流水线，得到一部**可以在流媒体与影展被认真对待**的剧集——故事立得住、人物不漂移、镜头有语言、声音有层次、母版合规范。

**"好莱坞级"的可操作定义**（本项目以此验收，不再用形容词）：

1. **剧作**：走过标准开发序列（logline → synopsis → treatment → beat sheet → outline → 剧本 → 修订），三幕/五幕结构与角色弧光可校验；
2. **前期**：有选角与定妆确认、分镜脚本与 previz（animatic），镜头语言（景别/角度/运镜/焦距/景深）在开拍前确定；
3. **摄影**：全片统一 2.39:1 主母版语法、24fps 电影感（180° 快门运动模糊）、多画幅安全框；
4. **表演与声音**：对白分层（production/ADR）、口型同步、四层声音设计（对白/音乐/音效/环境）、配乐有主题动机；
5. **后期**：有剪辑时间线（节奏与 J/L cut）、ACES 色彩管线、母版化输出；
6. **交付**：−23 LUFS / ≤−1 dBTP 归档母版、多规格交付（2.39/16:9/9:16、HDR10 可选）、影视级 QC 报告与交付单；
7. **治理**：五节点人工终审署名、预算硬约束、权利链可追溯、AI 标识合规。

## 四、端到端目标链路（影视工业流程 → AI 流水线）

```text
[Development]  立项与包型 → logline/synopsis → treatment → beat sheet → 分集大纲 → 剧本 → 修订
[Pre-pro]      选角与角色资产（定妆确认）→ 分镜脚本 → previz/animatic → 镜头清单与预算
[Production]   关键帧出图 → 镜头视频生成 → 表演/口型 → 变体与择优
[Post]         剪辑（时间线/节奏）→ 声音设计（对白/音效/环境/配乐）→ 混音 → 调色 → 母版
[Delivery]     影视 QC → 多规格交付 → 交付单与合规标识 → 分发与衍生版本
```

五个人工终审门禁（**不可跳过**）：**剧本 → 定妆 → 分镜 → 成片 → 母版**（依据：D6，见 [93-决策选举记录.md](93-决策选举记录.md)）。

## 五、已生效的决策决议（约束性）

以下六项由多智能体选举机制裁决（两轮共 37 次独立评估），**相关模块规格必须服从**：

| 决议 | 结果 | 约束要点 |
|------|------|----------|
| D1 画幅 | **2.39:1 主母版 + 16:9 平台版 + 9:16 衍生版** | 生成母版统一 16:9 open gate；2.39/9:16 由同一素材派生，禁止单画幅重复生成；生成阶段即建多画幅安全框 |
| D2 结构 | **剧集式：每集 22–45 分钟，6–12 集** | 首季默认 6 集 × 22–30 分钟；先导集过五门禁才解锁；每 2–3 集 go/kill；短形式为衍生层 |
| D3 声音 | **立体声 −23 LUFS/≤−1 dBTP + 5.1 可选** | 混音即锁定 5.1 stem 结构；5.1 需通过下混兼容测试，否则显式降级 |
| D4 色彩 | **ACES + Rec.709 主母版 + HDR10 可选** | 固化 AI 素材专用 IDT 并建色卡基线；HDR10 为独立下游 pass |
| D5 帧率 | **24fps 电影感 + 48fps 可选** | 锁唯一 24fps 时间线；快摇/动作镜头单独标注并做 judder QC |
| D6 门禁 | **AI 提议 + 人工终审（五节点）** | 署名审批、理由码、AI 异议不得静默覆盖、固定比例回溯抽检 |

完整票型、异议与强制缓解措施见 [93-决策选举记录.md](93-决策选举记录.md)（EL-01~EL-11 为派生硬性要求）。

## 六、产品原则

1. **流程优先于参数**：先有开发文档与门禁，再谈画质；流程决定下限。
2. **母版思维**：一次生成、多端派生；所有交付版本从同一母版自动化派生（EL-01/EL-05）。
3. **生成到镜头，组装到集**：集是组装与质检单元，返工粒度到镜头区间（EL-04）。
4. **一致性优先于单帧美感**：与角色不像的"漂亮镜头"判为不合格。
5. **不重复付费**：重试必须能证明上次结果不可用；宁可转人工也不盲目重发。
6. **质量可度量**：每个质量维度都有指标与阈值，没有阈值不算验收标准。
7. **门禁要有人负责**：五节点署名终审，签字有成本（EL-10）。
8. **先对齐工业标准，再谈创新**：成熟做法直接抄作业。

## 八、范围

**本期做**

- 影视工业流程落地：开发文档序列、选角定妆、分镜与 previz、五节点署名门禁
- VFX 与合成：AI 素材修复（穿模/手部/闪烁）、合成叠加、超分补帧与电影质感、物理骨架特效通道
- 电影化技术栈：2.39:1 母版语法、24fps 电影感、多画幅安全框、ACES 色彩管线、母版化输出
- 声音工业化：四层声音设计、配乐主题、混音标准与 stem 管理
- 后期能力：剪辑时间线（编辑即生效）、节奏与 J/L cut、局部重合成
- 交付能力：影视 QC 清单、多规格交付（含 9:16 衍生与可选 5.1/HDR10/48fps）、交付单
- 治理能力：预算硬约束、权利链台账、AI 标识与分级披露
- 长形式产能：22–45 分钟/集的长集生成与组装（生成到镜头粒度）

**本期不做**

- 自建基础模型训练（以供应商接入 + 可选自托管开源组件为主）
- 达芬奇/PR 级别的全功能 NLE（做"够用的电影化剪辑"）
- 影院 DCP 交付通道（OD-04，首季成片后再评估）
- 面向第三方的开放平台与计费系统

## 十、非功能需求（NFR）

| 编号 | 指标 | 目标值 | 测量方式 | 兜底策略 |
|------|------|--------|----------|----------|
| NFR-01 | 重复付费调用 | 0 次（同阶段同输入指纹） | 供应商调用日志按指纹去重 | 命中即拒绝提交并告警 |
| NFR-02 | 断点续跑成功率 | ≥ 99% | checkpoint 恢复次数 / 中断次数 | 恢复失败转人工并保留中间产物 |
| NFR-03 | 单集产出周期（22–30 分钟成片） | P1 ≤ 10 天 / P2 ≤ 5 天 | 集启动到母版通过的时间中位数 | 超期告警 + 优先调度 |
| NFR-04 | 单位成片成本 | P1 ≤ ¥400/分钟 / P2 ≤ ¥200/分钟（长形式精品区间） | 供应商账单折算 / 母版分钟数 | 超预算熔断转人工 |
| NFR-05 | 一次通过率（五门禁一次通过） | P1 ≥ 50% / P2 ≥ 75% | 未返工即过门的集占比 | 未达标触发自动返工或转人工 |
| NFR-06 | 人物一致性 | 人脸相似度 ≥0.45 通过 / 0.30–0.45 灰区（需自有剧集数据标定后冻结） | 抽帧 + 人脸嵌入比对（≥2 fps） | 灰区 VLM 复核；失败定向重滚（单镜 ≤2 次） |
| NFR-07 | 音画同步 | **整体偏移控制在 ITU-R BT.1359-1 容差 +90/−185 ms 内，工程目标 ≤±25 ms**；仅近景正脸镜做口型 | 口型链路记录音频→开口延迟 + 成片同步检测（Netflix `ANALYZER-Audio-OutOfSync` 同类，Lip Sync 必检） | 超限降级为不做口型或重做该镜（依据：B-26、B-27） |
| NFR-08 | 字幕与本地化 | 字准确率 ≥98%；**每条 5/6 s–7 s、≤2 行**；中文 **≤23 字符/行**（Originals 16）；竖屏 ≤3 行且不超中央 75% 纵向；落在 graphics safe（内缩 5%）内；禁硬字幕 | 时间戳由 TTS 字级产出、ASR 兜底；排版与安全区自动校验（依据：B-32、B-33、B-34、B-16、B-40） | 超限重做对齐或转人工 |
| NFR-09 | 画幅与安全框 | 100% 镜头通过 2.39/16:9/9:16 三画幅可裁切预演；**Title Safe 90% / Action Safe 93%（SMPTE ST 2046-1）或 EBU R95 的 3.5%/5%** | animatic 阶段逐镜校验 + 安全区自动检测（依据：B-14、B-16） | 不通过则该镜重做，不得靠后期硬补画 |
| NFR-10 | 帧率与运动质感 | 全片 24fps；judder 检出率 ≤2%（快摇/动作镜） | 时间线校验 + 运动抖动抽检 | 超限改用 48fps 生成后重映射 |
| NFR-11 | 声音交付 | 归档母版 **−23.0 LUFS（QC 容差 ±0.2 LU）/ 真峰值 ≤−1 dBTP**；广播版 −24 LKFS / <−2 dBTP；流媒体 −23~−27 LKFS；**对白高于掩蔽 ≥15 dB**；5.1 交付需通过下混兼容测试（中置/环绕 −3 dB） | 自动响度与真峰值 QC + 可懂度测量 + 下混 null 对比（依据：B-21、B-22、B-24、B-25） | 不通过即重混或显式降级为立体声 |
| NFR-12 | 色彩一致性 | 镜头间色偏以 **ITU-R BT.2124 色彩差异度量**统计；**ΔE 阈值无官方统一值（B-88），须立项时自定并写入 QC 报告**；ACES IDT 固定且版本化；交付文件色彩标签四元组齐全（B-87） | 色卡/灰阶基线 + 逐镜色偏统计 + mediainfo 标签核查 | 超限回滚到纯 Rec.709 降级路径 |
| NFR-13 | 影视 QC 通过率 | 技术 QC 项一次通过 ≥ 95%；**头尾黑场 ≥1 帧且 ≤1 s；母版 ProRes 422 HQ/4444 且 TC 嵌入；音频 24-bit/48 kHz**；无硬字幕/letterbox/上混/上采样 | QC 清单自动检测（依据：B-36~B-43） | 未通过阻断交付 |
| NFR-14 | 门禁留痕 | 五节点 100% 有署名、理由码与时间戳；回溯抽检覆盖率 ≥10% | 门禁记录审计 | 无署名视为未通过 |
| NFR-15 | 权利与合规 | 100% 成片可追溯素材权利链；AI 标识 100% 存在（画面 + 元数据 + 导出文件） | 权利台账 + 标识存在性校验 | 缺失禁止交付 |
| NFR-16 | 密钥与访问安全 | 密钥不入库不入 Git；媒体访问需鉴权 | 配置审计 + 越权测试 | 发现即回滚并轮换 |

## 十一、成功指标

**北极星指标**：**可交付母版分钟数 / 总成本**（每元产出多少分钟"能过门禁"的成片）。

过程指标：五门禁一次通过率、平均返工次数（镜头级）、人工介入分钟数、单位成片成本、重复付费调用数、人物一致性达标率、口型达标率、技术 QC 通过率、judder 检出率、色彩一致性达标率、集均产出周期。

业务指标：完播率、观看时长、平台过审率、衍生竖屏单元留存、版权与发行意向。

## 十四、核心术语

| 术语 | 定义 |
|------|------|
| 开发序列 | logline → synopsis → treatment → beat sheet → outline → 剧本 → 修订 的标准文档链 |
| 形象圣经（look bible） | 角色、场景、道具、色彩、光线的统一视觉规范，是一致性事实来源 |
| 定妆确认 | 角色形象正式锁定的人工门禁（五节点之一） |
| 分镜脚本 / animatic / previz | 镜头清单 → 动态分镜 → 预演，用于开拍前确认镜头语言 |
| 多画幅安全框 | 同一素材在 2.39:1 / 16:9 / 9:16 下都可成立的中心保护区约束 |
| 180° 快门 | 24fps 下 1/48s 快门，产生电影惯用的运动模糊 |
| judder | 24fps 下快速横摇产生的抖动/频闪 |
| ACES / IDT / ODT | 学院色彩编码系统；输入变换 / 输出变换 |
| 母版（master） | 归档级成片版本（本项目为 Rec.709 SDR + −23 LUFS），其余交付版本由它派生 |
| stem | 混音分轨（对白/音乐/音效/环境），5.1 与本地化的基础 |
| 交付单（delivery sheet） | 交付规格、版本、QC 结论、权利与标识状态的清单 |
| 五门禁 | 剧本 → 定妆 → 分镜 → 成片 → 母版 的署名终审节点 |
| 衍生层 | 由母版派生的短形式（60–90 秒竖屏）与平台版本，不新增生成 |
| 单位成片成本 | 供应商花费 / 合格母版分钟数 |
