# M15 素材资产与存储（L2）

- **模块编号**：M15
- **模块职责**：所有媒体（图/视频/音频/字幕/成片/母版）的存储、预处理、版本与血缘登记、检索与复用，并保证**母版唯一、多版本派生、权利可查**。
- **上游输入**：各阶段产出的媒体字节流与元数据；角色/场景/道具/声音/字体/曲库等可复用资产。
- **下游产出**：对象键与鉴权访问地址；资产族与版本谱系；镜头级血缘图；母版与派生版本清单。
- **对应页面/接口**：`/production` 资产库；`GET /api/dramas/:id/assets`（`apps/api/src/server.ts:412-413`）、`GET /api/dramas/:id/shots/:sid/(image|video)/(stream|download)`（`server.ts:356-377,451-460`）。
- **规则与依据**：画幅/声音/色彩/帧率/门禁的约束性决议见 [93-决策选举记录.md](93-决策选举记录.md)（EL-01~EL-11）；对标编号见 [99-业界对标与调研.md](99-业界对标与调研.md)；术语见 [00-项目背景.md](00-项目背景.md)。

## 2. 目标态差距小结

1. 存储层缺版本、版本谱系与血缘，导致「重跑即覆盖」，无法回滚、无法做影响分析，也无法证明母版唯一。
2. **没有资产族与母版概念**：2.39/16:9/9:16/HDR10/5.1/48fps 会被当成互不相关的文件，EL-01 与 EL-11 无从落地。
3. 缺抽帧与指纹能力，直接卡住 M6 一致性检测与 M10 质检；缺冷热分层与配额，长形式素材成本不可控。
4. 素材库当前只是台账：不支持上传、试听、复用，形象圣经与曲库授权也未资产化，权利信息无法支撑商用交付。
