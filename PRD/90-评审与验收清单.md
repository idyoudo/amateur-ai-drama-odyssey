# 评审与验收清单（附录）

> 好莱坞级 PRD 的评审入口：第一章评审方式，第二章进度，第三章规则自查，**第五章 P0 缺口（评审重点）**，第七章待决问题，第九章未取到原文的标准（不得作为验收阈值）。

## 一、评审方式

### 1.1 评审角色

| 角色 | 关注点 | 主要看 |
|------|--------|--------|
| 出品人 / showrunner | 包型、预算、门禁责任与路线 | L1 第二/七/八章、[93-决策选举记录](93-决策选举记录.md) |
| 导演 / 编剧 | 剧作开发、镜头语言、表演与节奏 | M2、M4、M5、M7、M9 |
| 摄影 / 视效 | 光学契约、布光、物理骨架与修复 | M5、M6、M19 |
| 声音 / 音乐 | 四层声音、混音标准、stem 交付 | M8、[91](91-影视技术规格与交付标准.md) |
| 后期 / 调色 / 交付 | 母版规格、QC 清单、交付合规 | M11、M12、[91](91-影视技术规格与交付标准.md) |
| 法务 / 合规 | 权利链、工会边界、分级与标识 | M18、[95](95-法律工会与行业准入标准.md) |
| 技术负责人 | 编排可靠性、成本、供应商能力 | M13、M14、M17、[99](99-业界对标与调研.md) |

### 1.2 评审顺序

1. [00-项目背景.md](00-项目背景.md)：愿景、影视工业流程、19 模块、16 条 NFR、三期路线图；
2. [93-决策选举记录.md](93-决策选举记录.md)：六项决议与其强制缓解措施（约束性）；
3. 差距最大的模块：M3 定妆 → M6 一致性连续性 → M4 previz → M5 电影摄影 → M19 VFX → M10 门禁 → M11 母版 → M18 法律；
4. 附录交叉核对：91（技术规格）、92（流程对标）、95（法律工会）、99（市场与开源）。

### 1.3 单条功能点通过标准
- [ ] 现状有代码证据（`file:line` 或链接式引用）或明确写「无」；
- [ ] 目标态规则清晰，`规划中` 有依据编号；
- [ ] 验收指标可二值判定或可量化；
- [ ] 优先级与依赖明确，与相邻模块无归属冲突。
