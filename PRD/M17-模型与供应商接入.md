# M17 模型与供应商接入（L2）

- **模块编号**：M17
- **模块职责**：定义可选模型与**电影参数能力矩阵**，封装文本/图像/视频/口型/语音/音乐/音效等供应商，并做按镜头路由、降级留痕、自托管评估与准入评测。
- **上游输入**：各阶段能力需求（参考图、首尾帧、多镜头、运镜、焦距景深、原生音频、画幅、时长、一致性、成本、时延）。
- **下游产出**：可调用的模型与稳定调用结果；能力矩阵与成本预估；降级与准入评测记录。
- **对应页面/接口**：`/dramas/new` 模型选择；`GET /api/dramas/models`（`apps/api/src/server.ts:337`）。
- **依据与规则**：能力与成本依据见 [99-业界对标与调研.md](99-业界对标与调研.md)（A-01~A-09、A-16~A-22、C-13、C-17~C-19、C-25~C-27、E-18/E-22、F-14/F-15）；可选交付与降级留痕见 [93-决策选举记录.md](93-决策选举记录.md)（EL-11）。

## 2. 目标态差距小结

1. 模型目录硬编码且只有单一视频供应商；**完全没有电影参数能力矩阵**，无法回答「哪个模型支持运镜/首尾帧/多镜头一次调用/原生音频」，M5 的镜头语言控制没有落地基础。
2. 无口型与音乐供应商（M7/M8 直接缺失）；TTS 只有单一端点，音色、情绪与时间戳能力位未登记。
3. 无按镜头路由与降级：项目固定模型，关键镜头与氛围镜同价；供应商故障即中断，且降级没有留痕义务。
4. 无自托管评估与许可风险清单，也没有准入评测：新模型靠试，GPL/非商用组件有内置分发风险。
