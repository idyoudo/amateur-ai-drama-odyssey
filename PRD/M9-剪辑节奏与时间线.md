# M9 剪辑、节奏与时间线（L2）

- **模块编号**：M9
- **模块职责**：把镜头素材变成**有节奏、可回改、可锁定、可交换**的成片时间线——编辑即生效的剪辑、ASL 节奏设计、J/L cut 技法、单镜替换与局部重合成、picture lock 与交换格式、合并成集、代理预览。
- **上游输入**：镜头视频与首尾帧（M5）、配音与口型（M7）、字幕/音乐/音效 stem（M8）、分镜与镜头清单（M4）、项目画幅与帧率（M1）。
- **下游产出**：锁定剪辑（Locked Cut）与版本谱系、EDL/XML/AAF 交换文件与回批校验报告、调色与混音交付素材、成片与合并集、代理预览。
- **对应页面/接口**：`/production` 时间线页签、`/dramas/$id`；`GET|PUT /api/dramas/:id/episodes/:episodeId/timeline`。
- **规则与依据**：画幅 D1、帧率 D5/EL-09、镜头级返工 EL-04、衍生层重剪 EL-05、母版与交换规格 B-36~B-42、剪辑方法论 E-53~E-62；编号含义见 [91](91-影视技术规格与交付标准.md)、[92](92-好莱坞制作流程对标.md)、[93](93-决策选举记录.md)。

## 1. 产品定位

剪辑是**唯一把「素材」变成「影片」的环节**：景别、表演、音乐的修辞都在切点上兑现。现状是「按镜顺序拼接」——时间线可存不可用（合成器从不读取它）、节奏不可设计、替换一个镜头要重编码全片。本模块定义目标态：**时间线是合成的唯一输入**，节奏用可度量的 ASL 曲线设计，剪点取舍按 Murch 权重排序（E-55），锁定后进入可回批的 exchange 流程。

边界：**画面内容质量归 M10**（本模块只做节奏与技术结构）；**母版编码与影视 QC 归 M11**；**品牌片头片尾样式归 M16**；**衍生的分发规格归 M12**（本模块提供按 act break 重剪的能力，EL-05）。

## 3. 目标态差距小结

1. **时间线是死的**：能存能取，但合成器完全不读它（`dramaWorker.ts:318,332-352`），所有剪辑操作都不影响成片——这是本模块最大的空洞。
2. **没有节奏概念**：镜长在生成期固化（`dramaService.ts:14`），无 ASL 曲线、无切点密度、无剪点取舍依据，只能用「硬切」表达一切。
3. **只有整体拼接，没有局部重合成**：逐镜重编码再 concat（`mediaComposer.ts:52-111`），替换一个镜头等于重做全片；已合成集还会被 `dramaWorker.ts:321-324` 短路复用。
4. **没有 lock、没有版本、没有交换格式**：无 TC 基线、无黑场、无命名规则、无 EDL/XML/AAF，因此无法与调色、混音、外包剪辑对接，也回答不了「送审的是哪一版」。
5. **合并止步于 3–5 分钟**：`episodeAssembly.ts:6` 只接受 180/240/300 s，长集成片（D2 的 22–45 分钟）尚无组装能力。
