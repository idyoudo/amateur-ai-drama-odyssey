# M12 交付、版本与分发（L2）

- **模块编号**：M12
- **模块职责**：把母版变成**符合合同与平台要求的交付物**：多规格派生、字幕与本地化、交付单、版本管理、分发与归档。
- **上游输入**：M11 输出的归档母版（Rec.709 SDR / −23 LUFS）与 stem。
- **下游产出**：多规格交付文件、交付单、版本谱系、分发与数据回流。
- **对应页面/接口**：`/production` 导出区、`/dramas/$id`；`POST|GET /api/dramas/:id/exports`、`POST /api/dramas/batch-exports`、`GET /api/media/:episodeId/(stream|download)`。

## 1. 产品定位

**交付不是"点导出"，是合同履约**：一份交付必须能回答——什么规格、什么版本、QC 结论如何、权利是否清晰、AI 标识是否具备、字幕与语言是否齐备。现状是"导出一个 mp4"（`format` 恒为 mp4，`apps/api/src/dramaProduction.ts:40-86`），规格由合成器硬编码（1280×720、aac，`apps/api/src/mediaComposer.ts:72-73`）。

**核心原则**：**一次生成、多端派生**——所有交付版本从同一母版自动派生，禁止为某一画幅/规格重复生成（EL-01/EL-05/EL-11）。

## 4. 目标态差距小结

1. 交付能力约等于零：只有一个 mp4，没有母版、没有派生、没有交付单。
2. 字幕口径冲突且无排版规范校验，不符合任何平台的 Timed Text 要求。
3. 没有版本谱系：无法回答"送审的是哪一版、上线的是哪一版"。
4. 缺归档与举证包，法律与发行场景都拿不出材料。
