# M14 成本、配额与度量治理（L2）

- **模块编号**：M14（对应 L1 模块地图 M14「预算硬阻断、缓存、熔断、单位成本度量」）
- **模块职责**：让「花多少钱、花在哪、值不值」变成可预测、可强制、可度量的能力——预算与配额是硬约束，成本口径对齐**影视交付物**而不是流水线中间产物。
- **上游输入**：各阶段调用产生的用量与费用；立项/集/pod/镜头四级预算与配额；门禁人力投入与返工记录。
- **下游产出**：预算拦截与降级决策、错峰排期建议、成本归因数据、母版成本与过程指标看板。
- **约束决议**：D2（包型与 pod）、D3（5.1 可选）、D4（HDR10 可选）、D5（48fps 可选）、D6（门禁）见 [93-决策选举记录.md](93-决策选举记录.md)；派生 EL-01/EL-03/EL-10/EL-11。
- **对应页面/接口**：`/production` 用量看板；`GET /api/content/usage-summary`、`POST /api/content/usage`。

## 1. 产品定位

本模块是「**单位可交付母版成本可控**」目标的兑现处。核心原则（依据见 [99-业界对标与调研.md](99-业界对标与调研.md) E/F 系列）：

1. **预算硬阻断**：超预算时阻断调用并隔离，而不是仅告警（E-17）。
2. **预占-结算**：调用前按估算预占额度，结束后结算差额（E-17）。
3. **不重复付费**：指纹命中即复用，重复付费调用硬性为 0（E-04、E-16）。
4. **降级不改故事**：省钱只能降分辨率/候选数/模型档位/交付规格，**不得改变叙事结构与镜头数**（E-18）。
5. **母版口径**：北极星分母是「可交付母版分钟数」，中间产物分钟数不得计入产出（F-04、F-16、F-17）。

## 3. 目标态差距小结

1. 当前用量是**手工上报的统计**，不是自动计量，更不是预算约束——无法阻止超支。
2. 成本口径停在「每分钟成片」，没有多规格派生、门禁人力与镜头级返工三块成本，长形式下会系统性低估。
3. 没有缓存与错峰排期概念，同一镜头重跑必然重新付费，且高价时段与错峰时段无差别使用。
4. 没有熔断与降级，供应商故障或价格波动只能靠人工发现。
5. 北极星指标与过程指标都缺「可交付」这个门禁约束，成本无法与质量放在一起决策。
